## 专项训练 02:00 — JavaScript 设计模式 v5 (cron)

**主题:** 代理模式 (Proxy) + 装饰器模式 (Decorator) — 两个未在 v1-v3 中覆盖的新模式
**文件大小:** ~21KB (05-proxy.md ~8.2KB + 06-decorator.md ~10KB)

### 覆盖内容

1. **代理模式 — 6 个实现:**
   - 基础 Proxy: get/set 拦截（属性校验/私有属性保护）
   - 响应式系统: Vue 3 核心实现（track/trigger + WeakMap 依赖收集 + 惰性嵌套代理）
   - 缓存代理: 计算结果缓存（斐波那契示例）
   - 只读代理: 深只读保护（拦截 set/delete/defineProperty/setPrototypeOf）
   - 函数参数校验代理: apply 陷阱 + 参数验证器
   - DOM 事件委托代理: 容器级事件代理（减少监听器数量）

2. **装饰器模式 — 5 个实现:**
   - 函数装饰器: withLogging/withRetry/withCache（可叠加组合）
   - Koa 洋葱模型: compose 将中间件数组变成嵌套 Promise 链（auth 短路/route/format）
   - 类装饰器: autobind/withStatic/serializable（模拟 @decorator 语法）
   - 对象装饰器（GoF 经典）: 咖啡点单系统（Espresso → Milk → Caramel → WhippedCream 链式叠加）
   - 方法装饰器: debounce/throttle/requireRole（属性描述符风格）

3. **模式对比:**
   - 代理 vs 装饰器: 代理控制访问（门卫），装饰器增强功能（加法）
   - 代理 vs 观察者: 代理一对一拦截操作，观察者一对多通知状态变化
   - 装饰器 vs 工厂: 工厂决定"创建哪个"，装饰器决定"叠加什么"

### 关键收获

- Proxy 是 JS 中最强大的设计模式 — 13 种拦截陷阱（get/set/has/delete/apply/construct...）
- Vue 3 响应式 = Proxy + track/trigger + WeakMap — 比 Object.defineProperty 更高效（支持动态属性/数组索引）
- Koa compose 本质 = 装饰器链的 Promise 化实现
- 装饰器可叠加是核心优势：withCache(withLogging(fn)) 一行搞定
- ES2022 Decorator 已进 Stage 3，TS 已支持 @decorator 语法
