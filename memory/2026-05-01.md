## 04:00 - 专项训练：Vue3 响应式系统源码精读 (阶段二 Day 1)

**文件**: `phase2-vue3/01-reactivity-source-reading.md` (~29KB)

**精读范围**: Vue 3.5+ reactivity 核心模块，5 个文件逐行分析

| 文件            | 内容                                                                         |
| --------------- | ---------------------------------------------------------------------------- |
| reactive.ts     | reactive/readonly/shallowReactive 入口 + createReactiveObject + WeakMap 缓存 |
| baseHandlers.ts | Proxy get/set/deleteProperty/has/ownKeys 拦截层                              |
| dep.ts          | Dep/Link 双向链表 + track/trigger + globalVersion 版本控制                   |
| effect.ts       | ReactiveEffect/run/stop/batch + prepareDeps/cleanupDeps + isDirty 脏检查     |
| ref.ts          | RefImpl + ref 自动解包 + ObjectRefImpl(toRef) + customRef                    |

**核心发现**:

1. Vue 3.5 用双向链表替代 Set 存储依赖，O(1) 增删 + 天然去重 + 版本控制
2. prepareDeps → 所有 link.version = -1 → 执行 fn() → cleanupDeps 移除 version 仍为 -1 的依赖 = 精确依赖
3. ref 和 reactive 的依赖存储不同：ref 用自身 dep，reactive 用 targetMap(target→key→Dep)
4. batch 机制：startBatch/endBatch 嵌套计数，逆序执行（子组件先于父组件）
5. globalVersion 快速路径：computed 比较 globalVersion 跳过整个脏检查
6. trigger 的精细控制：ADD→ITERATE_KEY, 数组新增→length, 数组 length 缩短→被删索引
