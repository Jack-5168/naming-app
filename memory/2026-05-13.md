## 01:00 — persona-lab 性能优化 (cron)

### 发现的问题与修复

**1. Prisma 连接池爆炸 (严重)**
- 9 个文件各自 `new PrismaClient()`，每个实例创建独立连接池
- 修复：统一使用 `lib/prisma.ts` 单例
- 涉及文件：auth, payments, dual-test, growth, memberships, share, cache, push-notification, membership-benefits, rate-limiter

**2. Prisma 单例 bug (严重)**
- `lib/prisma.ts` 生产环境每次请求都创建新实例
- 修复：简化逻辑，生产环境单例 + 开发环境 global 缓存

**3. N+1 查询**
- `questions.ts` import 函数逐条创建 → 改为事务批量
- `growth.ts` 串行查询 referrals + commissions → 改为 `Promise.all` 并行

**4. 缺失缓存**
- content 分类/标签接口（读多写少）→ 添加 24h LRU 缓存
- memberships 产品列表 → 添加 24h LRU 缓存
- cache.ts 新增 CATEGORIES/TAGS/MEMBERSHIP_PRODUCTS TTL

**5. Miniapp 构建优化**
- 启用构建缓存 (`cache.enable: true`)
- 图片 base64 阈值 1KB → 8KB（减少 HTTP 请求）
- 添加 webpack splitChunks 代码分割
