# 算法训练 2026-04-28 — 数组/字符串/哈希表

## 题目列表

### 简单题（3道）

**1. 两数之和（Two Sum）**

- 题目：给定整数数组 nums 和目标值 target，找出和为 target 的两个数的索引。
- 输入：nums = [2,7,11,15], target = 9
- 输出：[0,1]
- 思路：哈希表一次遍历，查找 target - nums[i] 是否已存在。
- 复杂度：O(n) 时间，O(n) 空间

**2. 有效的字母异位词（Valid Anagram）**

- 题目：判断字符串 s 是否是 t 的字母异位词。
- 输入：s = "anagram", t = "nagaram"
- 输出：true
- 思路：统计字符频次，两个字符串的字符分布应完全一致。
- 复杂度：O(n) 时间，O(1) 空间（26 个字母）

**3. 最长公共前缀（Longest Common Prefix）**

- 题目：找出字符串数组中最长的公共前缀。
- 输入：strs = ["flower","flow","flight"]
- 输出："fl"
- 思路：以第一个字符串为基准，逐字符比较所有字符串。
- 复杂度：O(m\*n) 时间（m=最短串长，n=字符串数），O(1) 空间

### 中等题（2道）

**4. 字母异位词分组（Group Anagrams）**

- 题目：将字符串数组中的字母异位词分组。
- 输入：strs = ["eat","tea","tan","ate","nat","bat"]
- 输出：[["bat"],["nat","tan"],["ate","eat","tea"]]
- 思路：对每个字符串排序作为 key，哈希表分组。
- 复杂度：O(n * k*logk) 时间（n=字符串数，k=字符串最大长度），O(n\*k) 空间

**5. 乘积最大子数组（Maximum Product Subarray）**

- 题目：找出乘积最大的连续子数组，返回最大乘积。
- 输入：nums = [2,3,-2,4]
- 输出：6
- 输入：nums = [-2,3,-4]
- 输出：48
- 思路：同时维护当前最大和最小乘积（负数会让最小变最大），动态规划。
- 复杂度：O(n) 时间，O(1) 空间
