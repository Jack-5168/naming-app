## 🧠 今日关键收获

### 算法与数据结构
1. 哈希表计数法：固定数组（字符集有限）vs Map（Unicode 支持）
2. 单调队列是滑动窗口最值问题的标准解法，O(n) 时间复杂度
3. 字母异位词分组：排序键简单但 O(nklogk)，计数键更优 O(nk)

### JavaScript 深度
4. 闭包本质是函数持有词法环境引用，V8 会做闭包裁剪优化
5. 寄生组合继承是 JS 继承的最优方案
6. 事件循环铁律：同步 → 清空微任务 → 渲染 → 一个宏任务 → 循环
7. Promise 状态机：pending → fulfilled/rejected，不可逆

### 设计模式
8. 工厂+策略组合：工厂负责创建策略对象，策略负责执行具体行为
9. 抽象工厂适合产品族场景，工厂方法适合单一产品等级

### 性能优化
10. CRP (Critical Rendering Path) 优化：减少关键资源、内联关键 CSS
11. Web Vitals 三指标：LCP < 2.5s, FID < 100ms, CLS < 0.1
12. 重排/重绘优化：使用 transform/opacity 而非 top/left

### 函数式编程
13. Transducer 实现零中间数组，3-5x 性能提升
14. Point-Free 风格要适度，过度使用会降低可读性
15. Lens 聚焦嵌套数据，Monad 处理副作用

### 网络与安全
16. 拦截器链模式是网络层封装的核心设计
17. 指数退避 + 随机抖动是重试机制的最佳实践
18. CSP 是防御 XSS 的最后一道防线
19. In-Flight 去重避免重复请求，提升性能

### 架构与设计
20. qiankun 微前端架构适合大型企业应用（JS 沙箱 + 样式隔离）
21. CSS Grid + Flexbox 是现代布局的两大支柱
22. ARIA landmark roles 和语义化 HTML 是无障碍的基础
23. JSON-LD 结构化数据对 SEO 至关重要
24. REST vs GraphQL 选型：简单 CRUD 用 REST，复杂查询用 GraphQL
