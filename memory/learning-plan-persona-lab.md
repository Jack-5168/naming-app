## 执行规则

### 硬性规则

1. **禁止阶段一巩固** — 不再做与人格探索局无关的练习
2. **每个任务必须产出代码** — 不写纯文档式学习笔记
3. **代码必须提交到 persona-lab** — 每个任务 = 1-2 个 commit
4. **验收标准必须满足** — 不达标不进入下一个任务

### 学习方式

- **遇到问题 → 查文档/搜索 → 解决 → 继续** (不写学习笔记)
- **需要理解概念 → 直接在代码中实现 → 验证** (不写理论笔记)
- **每天结束 → 更新进度 + 提交代码** (不写日报)

### 密度保证

- 每个任务有明确的时间盒 (30-90 分钟)
- 超时未完成 → 记录卡点 → 进入下一个任务
- 每天 5 个任务，完成 3 个即算达标
