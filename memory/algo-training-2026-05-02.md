# 算法训练 2026-05-02 — 数组/字符串/哈希表

## 题目列表

### 简单题（3道）

**1. 存在重复元素（Contains Duplicate）**
- 题目：给定整数数组，如果任一值在数组中出现至少两次，返回 true；如果数组中每个元素都不相同，返回 false。
- 输入：nums = [1,2,3,1] → 输出：true
- 输入：nums = [1,2,3,4] → 输出：false
- 输入：nums = [1,1,1,3,3,4,3,2,4,2] → 输出：true
- 思路：Set 去重，比较 Set.size 与 nums.length；或排序后检查相邻元素。
- 复杂度：O(n) 时间，O(n) 空间（Set 方案）/ O(nlogn) 时间，O(1) 空间（排序方案）
- 考点：Set 去重 / 排序思维

**2. 多数元素（Majority Element）**
- 题目：给定大小为 n 的数组，找出其中的多数元素（出现次数 > ⌊n/2⌋）。
- 输入：nums = [3,2,3] → 输出：3
- 输入：nums = [2,2,1,1,1,2,2] → 输出：2
- 思路：Boyer-Moore 投票算法 — 维护候选者和计数器，遇到相同 +1，不同 -1，归零时换候选者。
- 复杂度：O(n) 时间，O(1) 空间
- 考点：Boyer-Moore 投票 / 哈希表计数

**3. 最长回文串（Longest Palindrome）**
- 题目：给定一个包含大小写字母的字符串 s，返回能通过它构造出来的最长回文串的长度。
- 输入：s = "abccccdd" → 输出：7（可构造 "dccaccd"）
- 输入：s = "a" → 输出：1
- 思路：统计每个字符出现次数，偶数次全部使用，奇数次减 1 后使用，最后如果有奇数次字符可以放中间 +1。
- 复杂度：O(n) 时间，O(1) 空间（52 个字母）
- 考点：字符频次统计 / 回文构造规律

### 中等题（2道）

**4. 最长连续序列（Longest Consecutive Sequence）**
- 题目：给定未排序的整数数组，找出数字连续的最长序列（不要求元素在数组中连续）的长度。
- 输入：nums = [100,4,200,1,3,2] → 输出：4（序列 [1,2,3,4]）
- 输入：nums = [0,3,7,2,5,8,4,6,0,1] → 输出：9（序列 [0,1,2,3,4,5,6,7,8]）
- 思路：将所有数字放入 Set，遍历每个数字，只在该数字是序列起点（num-1 不在 Set 中）时向后扩展计数。每个数字最多被访问 2 次。
- 复杂度：O(n) 时间，O(n) 空间
- 考点：Set 快速查找 / 避免重复计算 / 序列起点判断

**5. 字符串排列（Permutation in String）**
- 题目：给定两个字符串 s1 和 s2，如果 s2 包含 s1 的某个排列，返回 true。
- 输入：s1 = "ab", s2 = "eidbaooo" → 输出：true（s2 包含 "ba"）
- 输入：s1 = "ab", s2 = "eidboaoo" → 输出：false
- 思路：滑动窗口 + 字符频次数组。先统计 s1 的字符频次，再用长度为 s1.length 的窗口在 s2 上滑动，维护窗口内字符频次，与 s1 频次数组逐位比较。
- 复杂度：O(n) 时间（n=s2.length），O(1) 空间（26 个字母）
- 考点：滑动窗口 / 字符频次数组 / 定长窗口
