## 快速参考

### 懒加载适用场景
- 图片/视频资源
- 路由组件
- 大型数据列表
- 第三方脚本

### 防抖 vs 节流
| 场景 | 技术 | 理由 |
|------|------|------|
| 搜索框输入 | 防抖 | 等待用户停止输入 |
| 窗口 resize | 节流 | 定期执行即可 |
| 按钮点击 | 防抖 | 防止重复提交 |
| 滚动加载 | 节流 | 控制检查频率 |

### 内存泄漏常见原因
- 未清理的定时器
- 未移除的事件监听器
- 闭包引用过大对象
- 分离的 DOM 节点
