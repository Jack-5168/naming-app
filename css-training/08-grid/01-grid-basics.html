示例 16: 伪瀑布流 (grid-auto-rows)

📱 移动端优先
先设计小屏，再逐步增强到大屏体验。
🎨 设计系统
统一的色彩、间距、字体规范让设计可复用。
⚡ 性能优化
减少重排重绘，使用 transform 和 opacity。
🔲 Grid vs Flex
Grid 适合二维布局，Flex 适合一维排列。
🌊 响应式
media query + clamp() 实现流体排版。
✨ 动画
GPU 加速的 transform 动画流畅不卡顿。
