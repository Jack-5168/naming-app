## 二、多语言 SEO — hreflang 完整实现

### 2.1 hreflang 基础

**hreflang 告诉搜索引擎同一内容的不同语言/地区版本，避免重复内容惩罚。**

```html
<!-- 每个语言版本页面都必须包含完整的 hreflang 集合 -->
<link rel="alternate" hreflang="zh-Hans" href="https://blog.example.com/zh/vue3-composition-api" />
<link rel="alternate" hreflang="en" href="https://blog.example.com/en/vue3-composition-api" />
<link rel="alternate" hreflang="ja" href="https://blog.example.com/ja/vue3-composition-api" />
<!-- x-default: 无匹配时的回退 -->
<link rel="alternate" hreflang="x-default" href="https://blog.example.com/en/vue3-composition-api" />
<!-- 自引用 canonical -->
<link rel="canonical" href="https://blog.example.com/zh/vue3-composition-api" />
```

### 2.2 hreflang 代码规范

| 代码格式 | 示例 | 说明 |
|----------|------|------|
| 语言 | `en` | 所有英语用户 |
| 语言+地区 | `en-US` | 美国英语 |
| 语言+地区 | `zh-Hans` | 简体中文（不论地区） |
| 地区回退 | `zh-Hant` | 繁体中文 |
| x-default | `x-default` | 无匹配时的默认页 |

### 2.3 多语言 SEO 常见错误

```
❌ 错误 1: 只放 hreflang 不放 canonical
→ 搜索引擎仍可能判定为重复内容

❌ 错误 2: hreflang 指向 404 页面
→ 所有语言版本受影响

❌ 错误 3: 语言版本内容差异过大
→ 搜索引擎可能忽略 hreflang

❌ 错误 4: 忘记 x-default
→ 未覆盖地区的用户看到错误版本

❌ 错误 5: hreflang 值大小写不一致
→ zh-hans vs zh-Hans 可能被当作不同值
```

```html
<!-- 阅读进度条 -->
```

```javascript
// 阅读进度更新（无障碍友好）
function updateReadingProgress() {
  const article = document.querySelector('article');
  const progressBar = document.querySelector('[role="progressbar"]');
  if (!article || !progressBar) return;

  const articleTop = article.getBoundingClientRect().top;
  const articleHeight = article.scrollHeight;
  const viewportHeight = window.innerHeight;
  const scrolled = Math.max(0, Math.min(1,
    (viewportHeight - articleTop) / (articleHeight + viewportHeight)
  ));
  const percent = Math.round(scrolled * 100);

  progressBar.setAttribute('aria-valuenow', percent);
  progressBar.setAttribute('aria-valuetext', `已阅读 ${percent}%`);
  progressBar.querySelector('.reading-progress__bar').style.width = `${percent}%`;
}

// 使用 rAF + 节流优化性能
let ticking = false;
window.addEventListener('scroll', () => {
  if (!ticking) {
    requestAnimationFrame(() => {
      updateReadingProgress();
      ticking = false;
    });
    ticking = true;
  }
}, { passive: true });
```

```html
<!-- ✅ 好的锚文本 -->
<p>
  使用 <a href="/ref-vs-reactive">ref 和 reactive 的区别</a> 可以帮你选择合适的响应式 API。
  更多关于 <a href="/vue3-reactivity-deep-dive">响应式原理的深度解析</a>，请参考我们的系列文章。

  <a href="/vue3-reactivity-deep-dive">查看更多</a>。
</p>
```

**内部链接 SEO 原则：**
1. 锚文本描述目标页面内容（非"点击这里"）
2. 每个页面至少 3-5 个内部链接指向站内相关内容
3. 使用分类/标签页作为聚合节点
4. 避免过度链接（每 100 字不超过 2-3 个链接）
5. 链接深度不超过 3 层（首页 → 分类 → 文章）

```javascript
// 评论表单验证
const form = document.getElementById('comment-form');

form.addEventListener('submit', (e) => {
  e.preventDefault();
  let isValid = true;

  // 验证姓名
  const name = form.name;
  const nameError = document.getElementById('name-error');
  if (!name.value.trim() || name.value.length < 2) {
    nameError.textContent = '姓名至少需要 2 个字符';
    name.setAttribute('aria-invalid', 'true');
    nameError.setAttribute('role', 'alert');
    isValid = false;
  } else {
    nameError.textContent = '';
    name.removeAttribute('aria-invalid');
  }

  // 验证邮箱
  const email = form.email;
  const emailError = document.getElementById('email-error');
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  if (!emailRegex.test(email.value)) {
    emailError.textContent = '请输入有效的邮箱地址';
    email.setAttribute('aria-invalid', 'true');
    isValid = false;
  } else {
    emailError.textContent = '';
    email.removeAttribute('aria-invalid');
  }

  // 验证评论内容
  const body = form.body;
  const bodyError = document.getElementById('body-error');
  if (body.value.length < 10) {
    bodyError.textContent = '评论内容至少需要 10 个字符';
    body.setAttribute('aria-invalid', 'true');
    isValid = false;
  } else {
    bodyError.textContent = '';
    body.removeAttribute('aria-invalid');
  }

  if (isValid) {
    // 提交评论
    const formData = new FormData(form);
    fetch('/api/comments', {
      method: 'POST',
      body: JSON.stringify(Object.fromEntries(formData)),
      headers: { 'Content-Type': 'application/json' }
    }).then(response => {
      if (response.ok) {
        // 通知屏幕阅读器
        const liveRegion = document.createElement('div');
        liveRegion.setAttribute('role', 'status');
        liveRegion.setAttribute('aria-live', 'polite');
        liveRegion.textContent = '评论已提交，等待审核后显示';
        document.body.appendChild(liveRegion);
        setTimeout(() => liveRegion.remove(), 5000);
        form.reset();
      }
    });
  } else {
    // 聚焦到第一个错误字段
    const firstError = form.querySelector('[aria-invalid="true"]');
    firstError?.focus();
  }
});
```

```javascript
const prefersDark = window.matchMedia('(prefers-color-scheme: dark)');

  themeToggle.setAttribute('aria-pressed', String(dark));
```

```javascript
const lazyImages = document.querySelectorAll('.lazy-image');
const imageObserver = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
```

### SEO 与 A11y 的持续交集

```
SEO 和 A11y 的核心交集始终围绕同一个原则：
让内容对所有人（包括搜索引擎爬虫和辅助技术用户）都是可理解的。

R5 特别强调：
1. 结构化数据 = 搜索引擎的理解 + 辅助技术的语义
2. hreflang = 多语言用户 + 多语言爬虫
3. 代码块 A11y = 开发者读者 + 屏幕阅读器用户
4. 评论系统 = 互动内容 + 表单无障碍
5. 分页策略 = 避免重复内容 + 清晰导航
```
