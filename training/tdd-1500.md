## 1. TDD 核心哲学

### 1.1 什么是 TDD？

```
TDD = Test-Driven Development (测试驱动开发)

核心循环：RED → GREEN → REFACTOR

RED    → 写一个失败的测试 (知道它应该通过但还没写实现)
GREEN  → 写最少代码让测试通过
REFACTOR → 重构代码，保持测试通过
```

### 1.2 TDD vs 传统开发

```
传统开发：写功能 → 手动测试 → 发现 Bug → 修复 → 可能引入新 Bug
TDD 开发：写测试 → 写功能 → 自动验证 → 安全重构 → 回归测试

TDD 优势：
✅ 设计先行：测试即文档，API 设计更合理
✅ 回归保护：每次修改都有安全网
✅ 代码质量：可测试的代码 = 低耦合高内聚
✅ 信心重构：大胆重构，测试保证行为不变
```

### 1.3 测试金字塔

```
           /\
          /  \         ← E2E 测试 (少而精)
         / E2E \        10-20 个，覆盖核心用户路径
        /-------\
       /  Integration \  ← 集成测试
      /   (API + DB)   \   中等数量，验证模块交互
     /-----------------\
    /    Component Test    \  ← 组件测试
   /   (React/Vue 组件)    \  较多，覆盖 UI 交互
  /-------------------------\
 /       Unit Test            \  ← 单元测试
/    (函数/工具/逻辑)          \   最多，覆盖所有边界
/_______________________________\
```

### 3.2 GREEN — 实现代码

```typescript
// src/counter.ts
export interface Counter {
  getValue(): number;
  increment(step?: number): Counter;
  decrement(step?: number): Counter;
  reset(value?: number): void;
}

export function createCounter(initialValue = 0): Counter {
  let value = initialValue;

  return {
    getValue() {
      return value;
    },
    increment(step = 1) {
      value += step;
      return this;
    },
    decrement(step = 1) {
      value -= step;
      return this;
    },
    reset(valueToReset = 0) {
      value = valueToReset;
    },
  };
}
```

### 3.3 REFACTOR — 优化实现

```typescript
// src/counter.ts (重构版 — 使用 Class)
export class Counter {
  private value: number;

  constructor(initialValue = 0) {
    this.value = initialValue;
  }

  getValue(): number {
    return this.value;
  }

  increment(step = 1): this {
    this.value += step;
    return this;
  }

  decrement(step = 1): this {
    this.value -= step;
    return this;
  }

  reset(value = 0): void {
    this.value = value;
  }

  // 新增：获取变化历史
  private history: number[] = [this.value];

  getHistory(): readonly number[] {
    return [...this.history];
  }
}
```

```typescript
// 新增测试
describe('Counter 重构版', () => {

    const counter = new Counter(0);
    counter.increment();
    counter.increment(3);
    counter.decrement(1);
    expect(counter.getHistory()).toEqual([0, 1, 4, 3]);
  });
});
```

## 4. 实战二：TodoList 组件 (Component Test)

> 场景：React Testing Library 组件测试，覆盖用户交互

### 4.1 TodoList 组件

```tsx
// src/TodoList.tsx
import React, { useState, useCallback } from 'react';

export interface Todo {
  id: string;
  text: string;
  completed: boolean;
  createdAt: Date;
}

interface TodoListProps {
  initialTodos?: Todo[];
  onAdd?: (todo: Todo) => void;
  onToggle?: (id: string) => void;
  onDelete?: (id: string) => void;
  onFilter?: (filter: FilterType) => void;
}

export type FilterType = 'all' | 'active' | 'completed';

export const TodoList: React.FC<TodoListProps> = ({
  initialTodos = [],
  onAdd,
  onToggle,
  onDelete,
  onFilter,
}) => {
  const [todos, setTodos] = useState<Todo[]>(initialTodos);
  const [inputValue, setInputValue] = useState('');
  const [filter, setFilter] = useState<FilterType>('all');
  const [editingId, setEditingId] = useState<string | null>(null);
  const [editValue, setEditValue] = useState('');

  const addTodo = useCallback(() => {
    const trimmed = inputValue.trim();
    if (!trimmed) return;

    const newTodo: Todo = {
      id: crypto.randomUUID(),
      text: trimmed,
      completed: false,
      createdAt: new Date(),
    };

    setTodos(prev => [...prev, newTodo]);
    setInputValue('');
    onAdd?.(newTodo);
  }, [inputValue, onAdd]);

  const toggleTodo = useCallback((id: string) => {
    setTodos(prev =>
      prev.map(todo =>
        todo.id === id ? { ...todo, completed: !todo.completed } : todo
      )
    );
    onToggle?.(id);
  }, [onToggle]);

  const deleteTodo = useCallback((id: string) => {
    setTodos(prev => prev.filter(todo => todo.id !== id));
    onDelete?.(id);
  }, [onDelete]);

  const startEdit = useCallback((todo: Todo) => {
    setEditingId(todo.id);
    setEditValue(todo.text);
  }, []);

  const saveEdit = useCallback(() => {
    if (!editingId) return;
    const trimmed = editValue.trim();
    if (!trimmed) return;

    setTodos(prev =>
      prev.map(todo =>
        todo.id === editingId ? { ...todo, text: trimmed } : todo
      )
    );
    setEditingId(null);
    setEditValue('');
  }, [editingId, editValue]);

  const clearCompleted = useCallback(() => {
    setTodos(prev => prev.filter(todo => !todo.completed));
  }, []);

  const filteredTodos = todos.filter(todo => {
    if (filter === 'active') return !todo.completed;
    if (filter === 'completed') return todo.completed;
    return true;
  });

  const activeCount = todos.filter(t => !t.completed).length;
  const completedCount = todos.filter(t => t.completed).length;

  const handleKeyDown = (e: React.KeyboardEvent) => {
    if (e.key === 'Enter') addTodo();
  };

  return (
    <div data-testid="todo-list" className="todo-list">
      <div className="todo-input">
        <input
          data-testid="todo-input"
          type="text"
          value={inputValue}
          onChange={e => setInputValue(e.target.value)}
          onKeyDown={handleKeyDown}
          placeholder="添加新任务..."
          aria-label="新任务输入框"
        />
        <button
          data-testid="add-button"
          onClick={addTodo}
          disabled={!inputValue.trim()}
        >
          添加
        </button>
      </div>

      <div className="todo-filters" role="group" aria-label="筛选">
        {(['all', 'active', 'completed'] as FilterType[]).map(f => (
          <button
            key={f}
            data-testid={`filter-${f}`}
            className={filter === f ? 'active' : ''}
            onClick={() => {
              setFilter(f);
              onFilter?.(f);
            }}
          >
            {f === 'all' ? '全部' : f === 'active' ? '未完成' : '已完成'}
          </button>
        ))}
      </div>

      <ul data-testid="todo-items">
        {filteredTodos.map(todo => (
          <li key={todo.id} data-testid={`todo-${todo.id}`}>
            {editingId === todo.id ? (
              <input
                data-testid={`edit-input-${todo.id}`}
                value={editValue}
                onChange={e => setEditValue(e.target.value)}
                onBlur={saveEdit}
                onKeyDown={e => e.key === 'Enter' && saveEdit()}
              />
            ) : (
              <span
                data-testid={`todo-text-${todo.id}`}
                className={todo.completed ? 'completed' : ''}
                onDoubleClick={() => startEdit(todo)}
              >
                {todo.text}
              </span>
            )}
            <input
              type="checkbox"
              checked={todo.completed}
              onChange={() => toggleTodo(todo.id)}
              data-testid={`todo-checkbox-${todo.id}`}
            />
            <button
              data-testid={`delete-button-${todo.id}`}
              onClick={() => deleteTodo(todo.id)}
              aria-label={`删除 ${todo.text}`}
            >
              ✕
            </button>
          </li>
        ))}
      </ul>

      <div className="todo-stats">
        <span data-testid="active-count">{activeCount} 个未完成</span>
        <span data-testid="completed-count">{completedCount} 个已完成</span>
        {completedCount > 0 && (
          <button data-testid="clear-completed" onClick={clearCompleted}>
            清除已完成
          </button>
        )}
      </div>
    </div>
  );
};
```

### 5.1 表单验证器实现

```typescript
// src/formValidator.ts
export interface ValidationRule {
  required?: boolean;
  minLength?: number;
  maxLength?: number;
  pattern?: RegExp;
  email?: boolean;
  custom?: (value: string) => string | null;
}

export interface ValidationResult {
  valid: boolean;
  errors: string[];
}

export interface FormSchema {
  [key: string]: ValidationRule;
}

export interface FormValues {
  [key: string]: string;
}

export interface FormErrors {
  [key: string]: string[];
}

const validators: Record<string, (value: string, rule: ValidationRule) => string | null> = {
  required(value, rule) {
    if (rule.required && (!value || !value.trim())) {
      return '此字段为必填项';
    }
    return null;
  },

  minLength(value, rule) {
    if (rule.minLength && value.length < rule.minLength) {
      return `最少需要 ${rule.minLength} 个字符`;
    }
    return null;
  },

  maxLength(value, rule) {
    if (rule.maxLength && value.length > rule.maxLength) {
      return `最多允许 ${rule.maxLength} 个字符`;
    }
    return null;
  },

  pattern(value, rule) {
    if (rule.pattern && !rule.pattern.test(value)) {
      return '格式不正确';
    }
    return null;
  },

  email(value, rule) {
    if (rule.email) {
      const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
      if (!emailRegex.test(value)) {
        return '请输入有效的邮箱地址';
      }
    }
    return null;
  },

  custom(value, rule) {
    if (rule.custom) {
      return rule.custom(value);
    }
    return null;
  },
};

export function validateField(value: string, rule: ValidationRule): ValidationResult {
  const errors: string[] = [];

  for (const [key, validator] of Object.entries(validators)) {
    const error = validator(value, rule);
    if (error) errors.push(error);
  }

  return {
    valid: errors.length === 0,
    errors,
  };
}

export function validateForm(
  values: FormValues,
  schema: FormSchema
): { valid: boolean; errors: FormErrors } {
  const errors: FormErrors = {};
  let valid = true;

  for (const [field, rule] of Object.entries(schema)) {
    const value = values[field] || '';
    const result = validateField(value, rule);

    if (!result.valid) {
      errors[field] = result.errors;
      valid = false;
    }
  }

  return { valid, errors };
}

// 常用 Schema 预设
export const schemas = {
  login: {
    email: { required: true, email: true },
    password: { required: true, minLength: 6 },
  } as FormSchema,

  register: {
    username: { required: true, minLength: 2, maxLength: 20 },
    email: { required: true, email: true },
    password: {
      required: true,
      minLength: 8,
      pattern: /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).+$/,
    },
    confirmPassword: {
      required: true,
      custom: (value) => null, // 需要外部比较
    },
  } as FormSchema,
};
```

```typescript
// src/cart.ts
export interface CartItem {
  id: string;
  name: string;
  price: number;
  quantity: number;
  maxQuantity?: number;
}

export interface CartState {
  items: CartItem[];
  totalAmount: number;
  totalQuantity: number;
}

export class ShoppingCart {
  private items: CartItem[] = [];
  private discountRate: number = 0;
  private couponCode: string | null = null;

  addItem(item: Omit<CartItem, 'quantity'>, quantity = 1): void {
    const existing = this.items.find(i => i.id === item.id);

    if (existing) {
      const maxQty = existing.maxQuantity || Infinity;
      existing.quantity = Math.min(existing.quantity + quantity, maxQty);
    } else {
      const maxQty = item.maxQuantity || Infinity;
      this.items.push({ ...item, quantity: Math.min(quantity, maxQty) });
    }
  }

  removeItem(id: string): void {
    this.items = this.items.filter(i => i.id !== id);
  }

  updateQuantity(id: string, quantity: number): void {
    const item = this.items.find(i => i.id === id);
    if (item) {
      if (quantity <= 0) {
        this.removeItem(id);
      } else {
        const maxQty = item.maxQuantity || Infinity;
        item.quantity = Math.min(quantity, maxQty);
      }
    }
  }

  increaseQuantity(id: string): void {
    const item = this.items.find(i => i.id === id);
    if (item) {
      const maxQty = item.maxQuantity || Infinity;
      item.quantity = Math.min(item.quantity + 1, maxQty);
    }
  }

  decreaseQuantity(id: string): void {
    const item = this.items.find(i => i.id === id);
    if (item) {
      if (item.quantity <= 1) {
        this.removeItem(id);
      } else {
        item.quantity -= 1;
      }
    }
  }

  clear(): void {
    this.items = [];
  }

  applyCoupon(code: string, discount: number): boolean {
    if (discount < 0 || discount > 1) return false;
    this.couponCode = code;
    this.discountRate = discount;
    return true;
  }

  removeCoupon(): void {
    this.couponCode = null;
    this.discountRate = 0;
  }

  getState(): CartState {
    const totalQuantity = this.items.reduce((sum, item) => sum + item.quantity, 0);
    const totalAmount = this.items.reduce(
      (sum, item) => sum + item.price * item.quantity,
      0
    );
    const discountedAmount = totalAmount * (1 - this.discountRate);

    return {
      items: [...this.items],
      totalAmount: Math.round(discountedAmount * 100) / 100,
      totalQuantity,
    };
  }

  getItem(id: string): CartItem | undefined {
    return this.items.find(i => i.id === id);
  }

  isEmpty(): boolean {
    return this.items.length === 0;
  }

  getItemCount(): number {
    return this.items.length;
  }
}
```

```typescript
// src/apiClient.ts
export interface ApiResponse<T> {
  data: T;
  status: number;
  message: string;
}

export interface User {
  id: number;
  name: string;
  email: string;
  role: 'admin' | 'user' | 'guest';
}

export interface PaginationParams {
  page: number;
  pageSize: number;
}

export interface PaginatedResponse<T> {
  data: T[];
  total: number;
  page: number;
  pageSize: number;
}

export class ApiClient {
  private baseUrl: string;
  private token: string | null = null;

  constructor(baseUrl: string) {
    this.baseUrl = baseUrl;
  }

  setToken(token: string): void {
    this.token = token;
  }

  async get<T>(path: string): Promise<ApiResponse<T>> {
    const url = `${this.baseUrl}${path}`;
    const headers: Record<string, string> = {
      'Content-Type': 'application/json',
    };
    if (this.token) {
      headers['Authorization'] = `Bearer ${this.token}`;
    }

    const response = await fetch(url, { headers });
    const data = await response.json();

    return {
      data: data as T,
      status: response.status,
      message: response.ok ? 'OK' : 'Error',
    };
  }

  async post<T>(path: string, body: unknown): Promise<ApiResponse<T>> {
    const url = `${this.baseUrl}${path}`;
    const headers: Record<string, string> = {
      'Content-Type': 'application/json',
    };
    if (this.token) {
      headers['Authorization'] = `Bearer ${this.token}`;
    }

    const response = await fetch(url, {
      method: 'POST',
      headers,
      body: JSON.stringify(body),
    });
    const data = await response.json();

    return {
      data: data as T,
      status: response.status,
      message: response.ok ? 'OK' : 'Error',
    };
  }

  async getUsers(params?: PaginationParams): Promise<PaginatedResponse<User>> {
    const queryParams = params
      ? `?page=${params.page}&pageSize=${params.pageSize}`
      : '';
    const response = await this.get<PaginatedResponse<User>>(
      `/users${queryParams}`
    );
    return response.data;
  }

  async getUserById(id: number): Promise<User> {
    const response = await this.get<User>(`/users/${id}`);
    return response.data;
  }

  async createUser(user: Omit<User, 'id'>): Promise<User> {
    const response = await this.post<User>('/users', user);
    return response.data;
  }
}
```

```typescript
import { useState, useEffect } from 'react';

export function useDebounce<T>(value: T, delay: number): T {
  const [debouncedValue, setDebouncedValue] = useState<T>(value);

  useEffect(() => {
    const timer = setTimeout(() => {
      setDebouncedValue(value);
    }, delay);

    return () => {
      clearTimeout(timer);
    };
  }, [value, delay]);

  return debouncedValue;
}
```

```typescript
// src/hooks/useLocalStorage.ts
import { useState, useCallback } from 'react';

export function useLocalStorage<T>(key: string, initialValue: T) {
  const [storedValue, setStoredValue] = useState<T>(() => {
    try {
      const item = window.localStorage.getItem(key);
      return item ? JSON.parse(item) : initialValue;
    } catch {
      return initialValue;
    }
  });

  const setValue = useCallback(
    (value: T | ((prev: T) => T)) => {
      try {
        const valueToStore = value instanceof Function ? value(storedValue) : value;
        setStoredValue(valueToStore);
        window.localStorage.setItem(key, JSON.stringify(valueToStore));
      } catch (error) {
        console.error('localStorage error:', error);
      }
    },
    [key, storedValue]
  );

  const removeValue = useCallback(() => {
    try {
      window.localStorage.removeItem(key);
      setStoredValue(initialValue);
    } catch (error) {
      console.error('localStorage remove error:', error);
    }
  }, [key, initialValue]);

  return { storedValue, setValue, removeValue };
}
```

### 9.1 Modal 组件

```tsx
// src/Modal.tsx
import React, { useEffect, useRef, useCallback } from 'react';

interface ModalProps {
  isOpen: boolean;
  onClose: () => void;
  title: string;
  children: React.ReactNode;
  size?: 'sm' | 'md' | 'lg';
  closeOnOverlay?: boolean;
  closeOnEsc?: boolean;
  showCloseButton?: boolean;
}

export const Modal: React.FC<ModalProps> = ({
  isOpen,
  onClose,
  title,
  children,
  size = 'md',
  closeOnOverlay = true,
  closeOnEsc = true,
  showCloseButton = true,
}) => {
  const overlayRef = useRef<HTMLDivElement>(null);
  const contentRef = useRef<HTMLDivElement>(null);

  const handleOverlayClick = useCallback(
    (e: React.MouseEvent) => {
      if (closeOnOverlay && e.target === overlayRef.current) {
        onClose();
      }
    },
    [closeOnOverlay, onClose]
  );

  const handleKeyDown = useCallback(
    (e: React.KeyboardEvent) => {
      if (closeOnEsc && e.key === 'Escape') {
        onClose();
      }
    },
    [closeOnEsc, onClose]
  );

  if (!isOpen) return null;

  const sizeClasses = {
    sm: 'modal-sm',
    md: 'modal-md',
    lg: 'modal-lg',
  };

  return (
    <div
      ref={overlayRef}
      data-testid="modal-overlay"
      className="modal-overlay"
      onClick={handleOverlayClick}
      onKeyDown={handleKeyDown}
      role="presentation"
    >
      <div
        ref={contentRef}
        data-testid="modal-content"
        className={`modal ${sizeClasses[size]}`}
        role="dialog"
        aria-modal="true"
        aria-labelledby="modal-title"
      >
        <div className="modal-header">
          <h2 id="modal-title" data-testid="modal-title">
            {title}
          </h2>
          {showCloseButton && (
            <button
              data-testid="modal-close"
              onClick={onClose}
              aria-label="关闭"
            >
              ✕
            </button>
          )}
        </div>
        <div className="modal-body" data-testid="modal-body">
          {children}
        </div>
      </div>
    </div>
  );
};
```

### 10.1 防抖实现

```typescript
// src/debounce.ts
export function debounce<T extends (...args: any[]) => any>(
  func: T,
  delay: number
): (...args: Parameters<T>) => void {
  let timeoutId: ReturnType<typeof setTimeout> | null = null;

  const debounced = (...args: Parameters<T>) => {
    if (timeoutId !== null) {
      clearTimeout(timeoutId);
    }
    timeoutId = setTimeout(() => {
      timeoutId = null;
      func(...args);
    }, delay);
  };

  debounced.cancel = () => {
    if (timeoutId !== null) {
      clearTimeout(timeoutId);
      timeoutId = null;
    }
  };

  debounced.flush = () => {
    if (timeoutId !== null) {
      clearTimeout(timeoutId);
      timeoutId = null;
      func();
    }
  };

  return debounced;
}
```

```typescript
// 新实现
export class PriorityQueue {
  private items: { element: string; priority: number }[] = [];

  size(): number {
    return this.items.length;
  }

  enqueue(element: string, priority: number): void {
    this.items.push({ element, priority });
  }

  dequeue(): string | undefined {
    if (this.items.length === 0) return undefined;

    let minIndex = 0;
    for (let i = 1; i < this.items.length; i++) {
      if (this.items[i].priority < this.items[minIndex].priority) {
        minIndex = i;
      }
    }

    return this.items.splice(minIndex, 1)[0].element;
  }

  peek(): string | undefined {
    if (this.items.length === 0) return undefined;

    let minIndex = 0;
    for (let i = 1; i < this.items.length; i++) {
      if (this.items[i].priority < this.items[minIndex].priority) {
        minIndex = i;
      }
    }

    return this.items[minIndex].element;
  }

  isEmpty(): boolean {
    return this.items.length === 0;
  }

  clear(): void {
    this.items = [];
  }
}
```

## 13. 面试高频考点

### 13.1 TDD 相关

**Q: TDD 的三大定律是什么？**

> A: Bob Martin 提出的 TDD 三大定律：
> 1. 在编写失败的单元测试之前，不允许编写生产代码
> 2. 只允许编写刚好足以导致失败的单位测试（编译失败也算失败）
> 3. 只允许编写刚好足以通过当前失败测试的生产代码

**Q: TDD 的优缺点？**

> 优点：
> - 设计先行，API 更合理
> - 回归保护，重构安全
> - 测试即文档
> - 代码覆盖率有保障
>
> 缺点：
> - 初期速度慢
> - 学习曲线陡峭
> - 不适合探索性编程
> - 过度依赖可能导致测试耦合

**Q: 什么是 Mock、Stub、Spy？**

> - **Mock**: 预设行为 + 验证调用（预设期望，验证是否满足）
> - **Stub**: 提供预设返回值（只回答，不验证）
> - **Spy**: 记录调用信息（观察行为，不预设）

```typescript
// Spy 示例
const spy = vi.fn();
spy('hello');
spy('world');
expect(spy).toHaveBeenCalledTimes(2);
expect(spy).toHaveBeenNthCalledWith(1, 'hello');

// Mock 示例
vi.spyOn(global, 'fetch').mockResolvedValue({ ok: true });

// Stub 示例
const stub = vi.fn().mockReturnValue(42);
```

### 13.2 Testing Library 相关

**Q: Testing Library 的核心理念？**

> "The more your tests resemble the way your software is used, the more confidence they can give you."
>
> 核心原则：
> - 测试行为，不测试实现细节
> - 用用户能看到的元素（文本、标签、角色）
> - 避免用 CSS class 或 test id（优先用 role/label/text）

**Q: 推荐的选择器优先级？**

```
1. getByRole    — 最推荐（语义化，接近用户视角）
2. getByLabelText — 表单元素
3. getByPlaceholderText — 占位符
4. getByText    — 文本内容
5. getByDisplayValue — 表单值
6. getByTestId  — 最后手段（仅当以上都不适用）
```

### 13.3 覆盖率相关

**Q: 100% 覆盖率有意义吗？**

> 没有。覆盖率是手段不是目的。
> - 90%+ 是合理目标
> - 关注边界条件和错误路径
> - 有些代码不值得测试（如纯 CSS 类名映射）
> - 质量 > 数量
