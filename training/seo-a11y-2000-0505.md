## 一、新闻/数据报道页 SEO 架构

### 1.1 页面类型特征

新闻/数据报道页的特殊性：
- **时效性强**：Google News 索引、Google Discover 推送
- **数据密集**：表格、图表、交互式可视化
- **多媒体丰富**：图片、视频、信息图
- **社交传播**：高分享率，OG/Twitter Card 至关重要
- **移动端优先**：70%+ 流量来自移动设备

## 二、数据表格无障碍（R6 核心新增）

### 2.1 简单表格 vs 复杂表格

| 类型 | 特征 | 解决方案 |
|------|------|----------|
| 简单表格 | 单行/单列表头 | `scope="col"` / `scope="row"` |
| 复杂表格 | 多行表头 / 分组表头 | `headers` 属性 + `scope` |
| 数据表格 | 大量数值数据 | `headers` + `data-label`（移动端回退） |
| 交叉表格 | 行和列都有多层级 | `headers` 属性指向多个 ID |

### 2.2 scope 属性的五种值

```html
<!-- scope 值及其含义 === -->
<th scope="col">列头</th>          <!-- 表头单元格属于其所在列 === -->
<th scope="row">行头</th>          <!-- 表头单元格属于其所在行 === -->
<th scope="colgroup">列组头</th>   <!-- 表头单元格属于其所在列组 === -->
<th scope="rowgroup">行组头</th>   <!-- 表头单元格属于其所在行组（tbody/tfoot） === -->
<th scope="auto">自动</th>         <!-- 浏览器自动推断（HTML5.2 新增） === -->
```

### 2.3 headers 属性的使用场景

当表格有多个层级的表头时，`scope` 不够用，需要用 `headers` 属性明确关联：

```html
<table>
  <thead>
    <tr>
```

## 四、懒加载 SEO 策略（R6 核心新增）

### 4.1 懒加载与 SEO 的矛盾

**问题：** 搜索引擎爬虫可能不会等待懒加载内容出现，导致内容不被索引。

**解决方案矩阵：**

| 策略 | SEO 友好 | A11y 友好 | 适用场景 |
|------|----------|-----------|----------|
| `loading="lazy"` + `<noscript>` | ✅ | ✅ | 图片懒加载（推荐） |
| IntersectionObserver + 初始渲染 | ✅ | ✅ | 首屏外内容 |
| 动态渲染（Dynamic Rendering） | ✅ | ⚠️ | JS 重度应用 |
| 服务端渲染（SSR/ISR） | ✅ | ✅ | 所有内容 |
| 纯 JS 懒加载（无回退） | ❌ | ❌ | 不推荐 |

### 4.2 图片懒加载 SEO 最佳实践

```html
<!-- ✅ 推荐：loading="lazy" + noscript 回退 === -->
<img
  src="/images/placeholder.webp"
  data-src="/images/full-res.webp"
  data-srcset="/images/480.webp 480w, /images/768.webp 768w, /images/1200.webp 1200w"
  alt="描述性替代文本"
  loading="lazy"
  decoding="async"
  width="800" height="450"
  class="lazyload"
>
<noscript>
  <img
    src="/images/full-res.webp"
    srcset="/images/480.webp 480w, /images/768.webp 768w, /images/1200.webp 1200w"
    alt="描述性替代文本"
    width="800" height="450"
  >
</noscript>

<!-- ❌ 不推荐：纯 background-image 懒加载 === -->
<!-- 搜索引擎无法索引 background-image === -->
<div class="lazy-bg" data-bg="/images/hero.webp"></div>
```

### 4.3 IntersectionObserver + 渐进增强

```javascript
// 懒加载内容：渐进增强，SEO 友好 ===
const lazyObserver = new IntersectionObserver((entries, observer) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const el = entry.target;
      
      // 加载内容
      if (el.dataset.src) {
        el.src = el.dataset.src;
        el.srcset = el.dataset.srcset;
      }
      
      // 触发内容加载（如 iframe、视频等）
      if (el.dataset.load === 'true') {
        el.removeAttribute('data-load');
        // 实际加载逻辑
      }
      
      observer.unobserve(el);
    }
  });
}, {
  rootMargin: '200px 0px',  // 提前 200px 开始加载
  threshold: 0.01
});

// 观察所有懒加载元素
document.querySelectorAll('[data-src], [data-load="true"]').forEach(el => {
  lazyObserver.observe(el);
});

// 渐进增强：如果 JS 不可用，<noscript> 回退确保内容可见
```

### 4.4 动态渲染（Dynamic Rendering）

对于 JS 重度应用（SPA），Google 推荐使用动态渲染：

```
用户（浏览器）→ 客户端渲染（SPA）
爬虫（Googlebot）→ 服务端渲染（预渲染 HTML）
```

```javascript
// 动态渲染中间件示例（Node.js/Express）===
const isBot = (userAgent) => {
  const bots = ['Googlebot', 'Bingbot', 'Baiduspider', 'YandexBot', 'facebookexternalhit', 'Twitterbot', 'WhatsApp'];
  return bots.some(bot => userAgent.includes(bot));
};

app.use(async (req, res, next) => {
  if (isBot(req.headers['user-agent'])) {
    // 爬虫：返回预渲染的 HTML ===
    try {
      const prerendered = await prerenderService.render(req.url);
      res.send(prerendered);
    } catch (err) {
      // 预渲染失败，回退到客户端渲染
      next();
    }
  } else {
    // 用户：正常 SPA 路由
    next();
  }
});
```

**注意：** Google 表示动态渲染不是 SEO 排名因素，只是让内容可被索引的手段。

## 五、无限滚动无障碍（R6 核心新增）

### 5.1 无限滚动的 A11y 问题

无限滚动（Infinite Scroll）的核心问题：
1. **无分页导航**：用户无法跳转到特定位置
2. **内容追加无通知**：屏幕阅读器不知道新内容已加载
3. **焦点管理混乱**：新内容可能夺取焦点
4. **无法书签/分享**：没有稳定的 URL

### 5.2 无限滚动 + 分页回退方案

```html
<!-- 方案：无限滚动 + 分页回退（推荐） === -->

<!-- 主要内容区 === -->
<main aria-label="文章列表">
  <article><!-- 文章 1 --></article>
  <article><!-- 文章 2 --></article>
  <article><!-- 文章 3 --></article>
  <!-- ... === -->
  
  <!-- 加载状态 === -->
  <div id="loading-indicator" role="status" aria-live="polite" aria-atomic="true" hidden>
    <span class="spinner" aria-hidden="true"></span>
    <span>正在加载更多内容...</span>
  </div>
  
  <!-- 分页导航（始终存在，JS 增强无限滚动） === -->
  <nav aria-label="分页导航" class="pagination">
    <a href="/page/1" aria-current="page">1</a>
    <a href="/page/2">2</a>
    <a href="/page/3">3</a>
    <span class="ellipsis" aria-hidden="true">…</span>
    <a href="/page/10">10</a>
    <a href="/page/2" rel="next">下一页 →</a>
  </nav>
</main>

<script>
// 无限滚动：渐进增强，分页回退始终可用 ===
const loadingIndicator = document.getElementById('loading-indicator');
const pagination = document.querySelector('.pagination');
let currentPage = 1;
let isLoading = false;

const scrollObserver = new IntersectionObserver(async (entries) => {
  if (entries[0].isIntersecting && !isLoading) {
    isLoading = true;
    loadingIndicator.hidden = false;
    
    try {
      const response = await fetch(`/page/${currentPage + 1}?json=1`);
      const data = await response.json();
      
      // 追加内容
      data.articles.forEach(article => {
        document.querySelector('main').insertAdjacentHTML('beforeend', article.html);
      });
      
      currentPage++;
      
      // 通知屏幕阅读器
      loadingIndicator.querySelector('span:last-child').textContent = 
        `已加载第${currentPage}页，新增${data.articles.length}篇文章`;
      
      // 更新分页链接
      updatePagination();
      
    } catch (err) {
      loadingIndicator.querySelector('span:last-child').textContent = '加载失败，请使用分页导航';
    } finally {
      isLoading = false;
      setTimeout(() => { loadingIndicator.hidden = true; }, 2000);
    }
  }
}, { rootMargin: '400px' });

// 观察分页导航区域（触发加载）
scrollObserver.observe(pagination);

// 分页导航始终可用（即使 JS 失败）
function updatePagination() {
  // 更新 aria-current 和 rel="next"
}
</script>
```

### 5.3 无限滚动无障碍检查清单

| 检查项 | 要求 |
|--------|------|
| 有分页回退 | 分页链接始终可用，不依赖 JS |
| 加载状态通知 | `role="status"` + `aria-live="polite"` |
| 焦点不丢失 | 新内容追加不移动焦点 |
| 可停止加载 | 提供"停止自动加载"按钮 |
| 内容可书签 | 分页 URL 稳定可分享 |
| 键盘可操作 | 分页链接可键盘导航 |
| 加载失败回退 | 失败时显示错误 + 引导使用分页 |

## 八、服务端渲染 SEO 策略（R6 核心新增）

### 8.1 渲染策略对比

| 策略 | SEO 友好 | 首屏速度 | 交互性 | 复杂度 | 适用场景 |
|------|----------|----------|--------|--------|----------|
| CSR（纯客户端） | ⚠️ 需动态渲染 | 慢 | 好 | 低 | 后台管理 |
| SSR（服务端渲染） | ✅ | 快 | 好 | 中 | 新闻/电商 |
| SSG（静态生成） | ✅ | 最快 | 好 | 低 | 博客/文档 |
| ISR（增量静态） | ✅ | 快 | 好 | 中 | 新闻（定期更新） |
| 动态渲染 | ✅ | 中 | 好 | 高 | SPA 应用 |
| 边缘渲染 | ✅ | 最快 | 好 | 高 | 全球化内容 |

### 8.2 ISR（增量静态再生）SEO 策略

新闻网站最适合 ISR：首次访问生成静态页面，后续按策略更新。

## 十、AMP（Accelerated Mobile Pages）与替代方案（R6 核心新增）

### 10.1 AMP 的现状

AMP 曾是 Google 移动搜索排名的加分项，但 2021 年后 Google 已不再将 AMP 作为排名因素。替代方案更灵活：

| 方案 | 优势 | 劣势 | 适用场景 |
|------|------|------|----------|
| AMP | Google News 收录快 | 限制 JS/CSS，自定义困难 | 新闻网站快速上线 |
| ESM + 边缘渲染 | 灵活 + 快速 | 需要边缘计算基础设施 | 现代新闻网站 |
| ISR + CDN | 静态 + 快速更新 | 需要框架支持 | Next.js/Nuxt 项目 |
| PWA | 离线 + 快速 | 需要 Service Worker | 高回访率网站 |

### 10.2 现代替代方案：ESM + 边缘渲染

```javascript
// Cloudflare Workers 边缘渲染示例 ===
export default {
  async fetch(request, env) {
    const url = new URL(request.url);
    
    // 爬虫请求：返回预渲染 HTML ===
    if (isBot(request.headers.get('user-agent'))) {
      const cached = await env.PRENDER_CACHE.get(url.pathname);
      if (cached) return new Response(cached, {
        headers: { 'Content-Type': 'text/html', 'Cache-Control': 'public, max-age=300' }
      });
      
      const html = await renderPage(url.pathname);
      await env.PRENDER_CACHE.put(url.pathname, html, { expirationTtl: 300 });
      return new Response(html, { headers: { 'Content-Type': 'text/html' } });
    }
    
    // 用户请求：返回 ESM SPA ===
    return env.ASSET_FETCHER.fetch(request);
  }
};
```
