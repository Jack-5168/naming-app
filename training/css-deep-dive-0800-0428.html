示例 24

响应式字体 — clamp() 函数

clamp(min, preferred, max) 让字体大小随视口自动缩放

大标题 — clamp(1.5rem, 4vw, 3rem)
副标题 — clamp(1rem, 2.5vw, 1.5rem)，调整浏览器宽度看效果
正文 — clamp(0.85rem, 1.5vw, 1rem)，永远不会太小或太大 
/* clamp(min, preferred, max) */
h1 { font-size: clamp(1.5rem, 4vw, 3rem); }
h2 { font-size: clamp(1rem, 2.5vw, 1.5rem); }
p  { font-size: clamp(0.85rem, 1.5vw, 1rem); }

/* 含义:
   - 最小值: 1.5rem (不会小于这个)
   - 首选值: 4vw (视口宽度的 4%)
   - 最大值: 3rem (不会大于这个) */

📋 总结

核心知识点速查

主题 核心属性 最佳场景
Flexbox flex-wrap, justify-content, align-items, flex:1, flex-shrink:0 一维布局 (行或列)
Grid grid-template-areas, auto-fill, minmax, span, dense 二维布局 (行+列)

Animation @keyframes, animation-delay, steps(), infinite 复杂多帧动画
响应式 @media, clamp(), auto-fill, minmax(), @container 多设备适配
