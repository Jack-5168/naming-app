## 1. SEO 优化详解

### 1.1 元标签优化

#### 基础 Meta 标签
```html
<!-- 字符编码和视口 -->
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta http-equiv="X-UA-Compatible" content="IE=edge">

<!-- 核心 SEO 元标签 -->
<title>文昌赐名 - 专业起名机构_诗经楚辞周易起名_宝宝取名专家</title>
<meta name="title" content="文昌赐名 - 专业起名机构_诗经楚辞周易起名_宝宝取名专家">
<meta name="description" content="文昌赐名专业起名机构，源自《诗经》《楚辞》《周易》等 20+ 先秦经典...">
<meta name="keywords" content="起名，取名，宝宝起名，婴儿取名，诗经起名，楚辞起名，周易起名...">
<meta name="author" content="文昌赐名">

<!-- 搜索引擎爬虫控制 -->
<meta name="robots" content="index, follow, max-image-preview:large, max-snippet:-1, max-video-preview:-1">
<meta name="googlebot" content="index, follow">
<meta name="baiduspider" content="all">
```

**关键点:**
- `title`: 50-60 字符，核心关键词前置
- `description`: 150-160 字符，包含主要关键词和行动号召
- `keywords`: 虽然 Google 不再使用，但百度仍参考
- `robots`: 控制索引和抓取行为

#### 规范链接 (Canonical)
```html
<link rel="canonical" href="https://jack-5168.github.io/naming-app/">
<link rel="alternate" hreflang="zh-CN" href="https://jack-5168.github.io/naming-app/">
<link rel="alternate" hreflang="x-default" href="https://jack-5168.github.io/naming-app/">
```

**作用:** 防止重复内容问题，指定首选 URL

## 2. 无障碍 (A11y) 优化详解

### 2.1 跳过导航链接 (Skip Link)

```html
<a href="#main-content" class="skip-link" style="position: absolute; left: -9999px; z-index: 999; padding: 1rem; background: #8B4513; color: white; text-decoration: none; font-weight: bold;">
    跳转到主要内容
</a>
```

**CSS:**
```css
.skip-link:focus {
    left: 0;
    top: 0;
    z-index: 10000;
}
```

**作用:** 允许键盘用户跳过导航直接到主要内容

### 2.2 ARIA 地标角色 (Landmarks)

```html
<!-- 页眉 -->
<header role="banner">...</header>

<!-- 主导航 -->
<nav role="navigation" aria-label="主导航">...</nav>

<!-- 主要内容 -->
<main id="main-content" role="main">...</main>

<!-- 页脚 -->
<footer role="contentinfo">...</footer>

<!-- 搜索区域 -->
<aside role="search">...</aside>

<!-- 补充信息 -->
<aside role="complementary">...</aside>
```

**屏幕阅读器快捷键:**
- `R` - 下一个地标
- `Shift+R` - 上一个地标

### 2.7 焦点管理

#### CSS 焦点样式
```css

button:focus {
    outline: 2px solid #8B4513;
    outline-offset: 2px;
}
```

#### JavaScript 焦点管理
```javascript
// Skip link focus
document.querySelector('.skip-link')?.addEventListener('click', function(e) {
    e.preventDefault();
    const mainContent = document.getElementById('main-content');
    if (mainContent) {
        mainContent.setAttribute('tabindex', '-1');
        mainContent.focus();
    }
});

// 汉堡菜单焦点陷阱
hamburgerMenu.addEventListener('click', function() {
    const isExpanded = this.getAttribute('aria-expanded') === 'true';
    this.setAttribute('aria-expanded', !isExpanded);
    mobileNavOverlay.setAttribute('aria-hidden', isExpanded);
    
    if (!isExpanded) {
        mobileNavClose?.focus();
    } else {
        hamburgerMenu.focus();
    }
});

// Escape 键关闭
document.addEventListener('keydown', function(e) {
    if (e.key === 'Escape' && hamburgerMenu.getAttribute('aria-expanded') === 'true') {
        mobileNavClose?.click();
    }
});
```

## 4. 核心知识点总结

### 4.1 SEO 核心原则

1. **内容优先**: 高质量、原创、有价值的内容是 SEO 的基础
2. **关键词策略**: 研究目标关键词，自然融入标题、描述、正文
3. **技术 SEO**: 确保网站可被搜索引擎抓取和索引
4. **结构化数据**: 使用 Schema.org 标记帮助搜索引擎理解内容
5. **性能优化**: 快速加载的网站排名更好
6. **移动优先**: 响应式设计，移动端体验至关重要
7. **内部链接**: 合理的内部链接结构传递权重

### 4.2 A11y 核心原则 (POUR)

1. **Perceivable (可感知)**
   - 提供文本替代 (alt 文本)
   - 提供字幕和替代媒体
   - 内容可适配 (响应式)
   - 前景背景和背景可区分

2. **Operable (可操作)**
   - 所有功能可键盘访问
   - 给用户足够时间阅读
   - 不要设计导致癫痫的内容
   - 帮助用户导航和查找内容

3. **Understandable (可理解)**
   - 文本可读可理解
   - 内容以可预测的方式运行
   - 帮助用户避免和纠正错误

4. **Robust (健壮)**
   - 最大化兼容性 (包括辅助技术)
   - 使用有效的 HTML
   - 正确使用 ARIA

### 4.3 WCAG 2.1 级别

- **A 级**: 最低要求 (必须满足)
- **AA 级**: 标准要求 (推荐达到)
- **AAA 级**: 最高标准 (可选)

**目标:** 至少达到 AA 级

### 补充知识点（4/27 新增）

#### 1. Web Vitals 与 SEO 的关系
- **LCP (Largest Contentful Paint)**: 影响 SEO 排名，目标 < 2.5s
- **INP (Interaction to Next Paint)**: 2024 年 3 月替代 FID，目标 < 200ms
- **CLS (Cumulative Layout Shift)**: 目标 < 0.1
- Google 将 Core Web Vitals 作为排名因素

#### 3. ARIA 最佳实践（ARIA 第一规则）
> **第一规则：不要使用 ARIA，除非 HTML 原生元素无法满足需求。**

- 用 `<button>` 而非 `<div role="button">`
- 用 `<nav>` 而非 `<div role="navigation">`（nav 本身隐含 navigation 角色）
- 用 `<h1>`-`<h6>` 而非 `<div role="heading">`
- ARIA 是增强，不是替代

#### 8. SEO 技术检查要点
- **hreflang 标签**: 多语言站点必备，防止内容重复
- **Sitemap**: XML 格式，包含所有重要页面，提交到 Google Search Console
- **Robots.txt**: 控制爬虫行为，但非安全机制
- **404 页面**: 自定义 404，包含导航链接和搜索框
- **301 重定向**: 页面迁移时使用，传递 SEO 权重
- **AMP**: 加速移动页面（可选，适合新闻类）
- **JavaScript SEO**: 确保关键内容在服务端渲染或预渲染

#### 9. 颜色对比度检查
- **正常文本**: 对比度 ≥ 4.5:1 (AA) / ≥ 7:1 (AAA)
- **大文本**: 对比度 ≥ 3:1 (AA) / ≥ 4.5:1 (AAA)
- **UI 组件**: 对比度 ≥ 3:1
- 工具: WebAIM Contrast Checker / Chrome DevTools
