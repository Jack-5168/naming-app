## 🟢 简单题 1 — 合并两个有序数组 (Merge Sorted Array)

**LeetCode 88** | 数组 + 双指针（逆向）

### 题目

给你两个按 **非递减顺序** 排列的整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n`，分别表示 `nums1` 和 `nums2` 中的元素数目。

请你 **原地** 合并 `nums2` 到 `nums1` 中，使合并后的数组同样按非递减顺序排列。

`nums1` 的初始长度为 `m + n`，其中前 `m` 个元素表示应合并的元素，后 `n` 个元素为 0，应忽略。

```
输入: nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
输出: [1,2,2,3,5,6]

输入: nums1 = [1], m = 1, nums2 = [], n = 0
输出: [1]
```

### 思路

**关键洞察：** 从后往前合并，避免覆盖 `nums1` 的有效元素。

- 三个指针：`i = m - 1`（nums1 有效元素末尾）、`j = n - 1`（nums2 末尾）、`k = m + n - 1`（合并后末尾）
- 比较 `nums1[i]` 和 `nums2[j]`，大的放 `nums1[k]`
- `nums2` 有剩余时直接复制到前面（`nums1` 有剩余则已在正确位置）

- 时间：O(m + n) — 一次遍历
- 空间：O(1) — 原地操作

### 代码

```typescript
function merge(nums1: number[], m: number, nums2: number[], n: number): void {
  let i = m - 1;
  let j = n - 1;
  let k = m + n - 1;

  while (i >= 0 && j >= 0) {
    if (nums1[i] > nums2[j]) {
      nums1[k--] = nums1[i--];
    } else {
      nums1[k--] = nums2[j--];
    }
  }

  // nums2 剩余元素复制到前面（nums1 剩余已在正确位置）
  while (j >= 0) {
    nums1[k--] = nums2[j--];
  }
}
```

### 变体思考

- **正向合并**：需要额外 O(m) 空间保存 `nums1` 前 m 个元素
- **为什么逆向更优**：`nums1` 尾部有足够空间，逆向写入不会覆盖未处理的有效元素

## 🟢 简单题 2 — 快乐数 (Happy Number)

**LeetCode 202** | 数学 + 快慢指针 / 哈希表

### 题目

编写一个算法来判断一个数 `n` 是不是快乐数。

「快乐数」定义为：
- 对于一个正整数，每一次将该数替换为它每个位置上的数字的平方和
- 然后重复这个过程直到这个数变为 1，也可能是 **无限循环** 但始终变不到 1
- 如果这个过程结果为 1，就是快乐数

```
输入: n = 19
输出: true
解释:
1² + 9² = 82
8² + 2² = 68
6² + 8² = 100
1² + 0² + 0² = 1 ✅

输入: n = 2
输出: false
解释: 2 → 4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4 ... (进入循环)
```

### 思路

**核心问题：检测循环。** 两种方法：

**方法一：哈希表（直观）**
- 用 Set 记录出现过的数字，遇到重复说明进入循环
- 时间：O(log n) 步数，每步 O(log₁₀ n) 计算平方和
- 空间：O(log n) — Set 存储

**方法二：快慢指针（O(1) 空间）**
- 类似链表环检测：slow 走一步，fast 走两步
- 如果 fast 先到 1 → 快乐数；如果 slow == fast → 有环，不快乐
- 空间：O(1)

### 代码

```typescript
// 方法一：哈希表
function isHappy(n: number): boolean {
  const seen = new Set<number>();

  function digitSquareSum(num: number): number {
    let sum = 0;
    while (num > 0) {
      const d = num % 10;
      sum += d * d;
      num = Math.floor(num / 10);
    }
    return sum;
  }

  let current = n;
  while (current !== 1 && !seen.has(current)) {
    seen.add(current);
    current = digitSquareSum(current);
  }

  return current === 1;
}

// 方法二：快慢指针（O(1) 空间）
function isHappyFastSlow(n: number): boolean {
  function digitSquareSum(num: number): number {
    let sum = 0;
    while (num > 0) {
      const d = num % 10;
      sum += d * d;
      num = Math.floor(num / 10);
    }
    return sum;
  }

  let slow = n;
  let fast = digitSquareSum(n);

  while (fast !== 1 && slow !== fast) {
    slow = digitSquareSum(slow);
    fast = digitSquareSum(digitSquareSum(fast));
  }

  return fast === 1;
}
```

### 关键洞察

- 为什么快慢指针能检测循环？和链表环检测同理——如果存在循环，快指针迟早追上慢指针
- 任何非快乐数最终都会进入 `4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4` 这个固定循环
- 对于 2147483647 以内的数，digitSquareSum 的结果不会超过 9² × 10 = 810，所以循环检测很快

## 🟢 简单题 3 — 同构字符串 (Isomorphic Strings)

**LeetCode 205** | 字符串 + 双向哈希映射

### 题目

给定两个字符串 `s` 和 `t`，判断它们是否是同构的。

如果 `s` 中的字符可以按某种映射关系替换得到 `t`，那么这两个字符串是同构的。
- 每个出现的字符都应当映射到另一个字符，同时不改变字符顺序
- 不同字符不能映射到同一个字符
- 相同字符只能映射到同一个字符
- 字符可以映射到自己

```
输入: s = "egg", t = "add"
输出: true
解释: e → a, g → d

输入: s = "foo", t = "bar"
输出: false
解释: o 需要同时映射到 a 和 r，冲突

输入: s = "paper", t = "title"
输出: true
解释: p → t, a → i, e → l, r → e
```

### 思路

**核心难点：双向一一映射。** 单向检查不够（"foo" → "bar" 中 o→a 和 o→r 冲突，但单向检查 o→a 时不会发现 o 还要映射到 r）。

需要两个哈希表：
- `sToT`：s 的字符 → t 的字符
- `tToS`：t 的字符 → s 的字符

遍历两个字符串，每一步检查双向映射是否一致。

- 时间：O(n) — 一次遍历
- 空间：O(1) — 最多存储 ASCII 字符集大小（256）的映射

### 代码

```typescript
function isIsomorphic(s: string, t: string): boolean {
  if (s.length !== t.length) return false;

  const sToT = new Map<string, string>();
  const tToS = new Map<string, string>();

  for (let i = 0; i < s.length; i++) {
    const sc = s[i];
    const tc = t[i];

    // 检查 s→t 映射
    if (sToT.has(sc)) {
      if (sToT.get(sc) !== tc) return false;
    } else {
      sToT.set(sc, tc);
    }

    // 检查 t→s 映射（防止不同字符映射到同一字符）
    if (tToS.has(tc)) {
      if (tToS.get(tc) !== sc) return false;
    } else {
      tToS.set(tc, sc);
    }
  }

  return true;
}
```

### 优化：用数组代替 Map

```typescript
function isIsomorphicArray(s: string, t: string): boolean {
  if (s.length !== t.length) return false;

  const sToT = new Array(256).fill(0);
  const tToS = new Array(256).fill(0);

  for (let i = 0; i < s.length; i++) {
    const si = s.charCodeAt(i);
    const ti = t.charCodeAt(i);

    if (sToT[si] !== tToS[ti]) return false;

    sToT[si] = i + 1; // 用 1-based 索引避免 0 的歧义
    tToS[ti] = i + 1;
  }

  return true;
}
```

**巧妙之处：** 用同一个索引值写入两个数组，如果两个字符是同构映射，它们在同一位置被写入相同的值；否则说明映射关系不一致。

## 🟡 中等题 1 — 旋转数组 (Rotate Array)

**LeetCode 189** | 数组 + 三次翻转 / 环状替换

### 题目

给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，`k` 是非负数。

**要求：** 使用空间复杂度 O(1) 的原地算法。

```
输入: nums = [1,2,3,4,5,6,7], k = 3
输出: [5,6,7,1,2,3,4]
解释:
向右轮转 1 步: [7,1,2,3,4,5,6]
向右轮转 2 步: [6,7,1,2,3,4,5]
向右轮转 3 步: [5,6,7,1,2,3,4]

输入: nums = [-1,-100,3,99], k = 2
输出: [3,99,-1,-100]
```

### 思路

**方法一：三次翻转（最优 O(1) 空间）**

核心思想：`[1,2,3,4,5,6,7]` 右旋 3 步 = `[5,6,7,1,2,3,4]`

```
原始:     [1,2,3,4,5,6,7]
翻转全部: [7,6,5,4,3,2,1]
翻转前k:  [5,6,7,4,3,2,1]
翻转后n-k:[5,6,7,1,2,3,4] ✅
```

三步：① 翻转整个数组 → ② 翻转前 k 个 → ③ 翻转后 n-k 个

**方法二：环状替换**
- 每个元素直接放到目标位置，被挤掉的元素继续放到它的目标位置
- 需要处理多环情况（gcd(n, k) 个环）

- 时间：O(n) — 三次翻转各 O(n)
- 空间：O(1) — 原地操作

### 代码

```typescript
function rotate(nums: number[], k: number): void {
  const n = nums.length;
  k = k % n; // 处理 k > n 的情况

  // 辅助函数：翻转数组的指定区间
  function reverse(start: number, end: number): void {
    while (start < end) {
      [nums[start], nums[end]] = [nums[end], nums[start]];
      start++;
      end--;
    }
  }

  // 三次翻转
  reverse(0, n - 1);       // 翻转全部
  reverse(0, k - 1);       // 翻转前 k 个
  reverse(k, n - 1);       // 翻转后 n-k 个
}

// 方法二：环状替换
function rotateCyclic(nums: number[], k: number): void {
  const n = nums.length;
  k = k % n;
  if (k === 0) return;

  const gcd = (a: number, b: number): number => (b === 0 ? a : gcd(b, a % b));
  const cycles = gcd(n, k); // 环的数量

  for (let start = 0; start < cycles; start++) {
    let current = start;
    let prev = nums[start];

    do {
      const next = (current + k) % n;
      [nums[next], prev] = [prev, nums[next]];
      current = next;
    } while (current !== start);
  }
}
```

### 关键洞察

- **为什么需要 `k % n`？** 旋转 n 次等于没旋转
- **三次翻转的通用性：** 适用于左旋/右旋，只需调整翻转区间
- **环状替换的数学基础：** gcd(n, k) 决定了需要多少个独立的环才能覆盖所有位置

## 🟡 中等题 2 — 最小窗口子串 (Minimum Window Substring)

**LeetCode 76** | 滑动窗口 + 字符计数

### 题目

给你两个字符串 `s` 和 `t`。返回 `s` 中涵盖 `t` 所有字符的最小子串。

如果 `s` 中不存在涵盖 `t` 所有字符的子串，则返回空字符串 `""`。

```
输入: s = "ADOBECODEBANC", t = "ABC"
输出: "BANC"
解释: "BANC" 是包含 A、B、C 的最小子串

输入: s = "a", t = "a"
输出: "a"

输入: s = "a", t = "aa"
输出: ""
解释: t 需要两个 a，s 只有一个
```

### 思路

**滑动窗口经典题。** 核心：扩展右边界直到窗口包含 t 的所有字符，然后收缩左边界找到最小窗口。

**算法步骤：**
1. 用 `need` 哈希表记录 t 中每个字符需要的数量
2. 右指针 `right` 扩展窗口，遇到需要的字符就减少 `need` 计数
3. 当窗口包含所有字符（`formed === required`），记录当前窗口
4. 左指针 `left` 收缩窗口，尝试找到更小的有效窗口
5. 收缩时如果某个字符移出窗口后不够了，停止收缩，继续扩展右边界

**关键变量：**
- `need`：记录 t 中每个字符的需求量
- `formed`：当前窗口中已满足需求量的不同字符数
- `required`：t 中不同字符的数量

- 时间：O(m + n) — 左右指针各遍历 s 一次
- 空间：O(1) — 字符集大小固定（最多 52 个英文字母）

### 代码

```typescript
function minWindow(s: string, t: string): string {
  if (s.length < t.length) return "";

  // 统计 t 中字符需求
  const need = new Map<string, number>();
  for (const c of t) {
    need.set(c, (need.get(c) || 0) + 1);
  }

  const required = need.size; // t 中不同字符的数量
  let formed = 0; // 当前窗口中已满足需求的字符种类数
  const windowCounts = new Map<string, number>();

  let left = 0;
  let right = 0;
  let minLen = Infinity;
  let minLeft = 0;

  while (right < s.length) {
    const c = s[right];
    windowCounts.set(c, (windowCounts.get(c) || 0) + 1);

    // 检查该字符是否满足需求
    if (need.has(c) && windowCounts.get(c) === need.get(c)) {
      formed++;
    }

    // 尝试收缩左边界
    while (left <= right && formed === required) {
      const windowLen = right - left + 1;
      if (windowLen < minLen) {
        minLen = windowLen;
        minLeft = left;
      }

      const leftChar = s[left];
      windowCounts.set(leftChar, windowCounts.get(leftChar)! - 1);

      // 如果移除后不够了，打破循环
      if (need.has(leftChar) && windowCounts.get(leftChar)! < need.get(leftChar)!) {
        formed--;
      }

      left++;
    }

    right++;
  }

  return minLen === Infinity ? "" : s.substring(minLeft, minLeft + minLen);
}
```

## 📊 总结

| # | 题目 | 核心模式 | 时间 | 空间 | 关键技巧 |
|---|------|---------|------|------|---------|
| 1 | 合并有序数组 | 逆向双指针 | O(m+n) | O(1) | 从后往前避免覆盖 |
| 2 | 快乐数 | 快慢指针判环 | O(log n) | O(1) | Floyd 环检测 |
| 3 | 同构字符串 | 双向映射 | O(n) | O(1) | 两个哈希表 / 索引技巧 |
| 4 | 旋转数组 | 三次翻转 | O(n) | O(1) | 翻转的数学性质 |
| 5 | 最小窗口子串 | 滑动窗口 | O(m+n) | O(1) | 扩展→收缩→记录 |

### 模式总结

1. **逆向双指针**：当需要原地修改且从前往后会覆盖数据时，考虑从后往前
2. **快慢指针判环**：任何"序列中检测循环"的问题都可以用 Floyd 算法
3. **双向一一映射**：判断同构/等价关系时，必须检查两个方向
4. **三次翻转**：数组旋转的 O(1) 空间最优解，本质是数学变换
5. **滑动窗口**：子串/子数组问题的高效模式，核心是"扩展找可行解，收缩找最优解"
