# 大五人格 (Big Five) 与 MBTI 映射说明

## 概述

本文档说明大五人格模型 (OCEAN) 与 MBTI 四个维度之间的理论映射关系，用于 Persona Lab 的预测试标定和人格类型推断。

---

## 大五人格模型 (Big Five / OCEAN)

| 维度 | 英文                       | 高分特征                         | 低分特征                 |
| ---- | -------------------------- | -------------------------------- | ------------------------ |
| O    | Openness (开放性)          | 想象力丰富、好奇心强、喜欢新体验 | 务实、传统、偏好熟悉事物 |
| C    | Conscientiousness (尽责性) | 自律、有条理、可靠               | 随意、灵活、可能拖延     |
| E    | Extraversion (外向性)      | 社交活跃、精力充沛、喜欢人群     | 内敛、安静、偏好独处     |
| A    | Agreeableness (宜人性)     | 合作、同情心强、信任他人         | 竞争性强、怀疑、直接     |
| N    | Neuroticism (神经质)       | 情绪敏感、易焦虑、情绪波动大     | 情绪稳定、冷静、抗压强   |

---

## MBTI 四个维度

| 维度 | 两极                        | 描述                           |
| ---- | --------------------------- | ------------------------------ |
| E/I  | Extraversion / Introversion | 能量来源：外部世界 vs 内心世界 |
| S/N  | Sensing / Intuition         | 信息获取：感官细节 vs 模式直觉 |
| T/F  | Thinking / Feeling          | 决策方式：逻辑分析 vs 价值情感 |
| J/P  | Judging / Perceiving        | 生活方式：计划结构 vs 灵活开放 |

---

## 映射关系

### 1. E/I (外向 - 内向) ↔ E (外向性)

**映射强度：强相关 (r ≈ 0.7-0.8)**

| MBTI     | Big Five E 得分 | 特征描述                               |
| -------- | --------------- | -------------------------------------- |
| E (外向) | 高分 (45-60)    | 社交活跃、精力充沛、喜欢人群、主动交流 |
| I (内向) | 低分 (12-30)    | 内敛安静、独处充电、深度交流、小圈子   |

**说明**: 这是两个体系中最直接对应的维度，概念高度重叠。

---

### 2. S/N (实感 - 直觉) ↔ O (开放性)

**映射强度：中强相关 (r ≈ 0.5-0.6)**

| MBTI     | Big Five O 得分 | 特征描述                                   |
| -------- | --------------- | ------------------------------------------ |
| N (直觉) | 高分 (45-60)    | 抽象思维、想象力丰富、喜欢理论、关注可能性 |
| S (实感) | 低分 (12-30)    | 具体思维、注重事实、偏好实际、关注现实     |

**说明**:

- N 型与高开放性高度相关，都喜欢抽象概念和新奇想法
- S 型与低开放性相关，更务实和传统
- 但并非完全等同，S/N 还涉及信息处理方式的差异

---

### 3. T/F (思考 - 情感) ↔ A (宜人性)

**映射强度：中等相关 (r ≈ 0.4-0.5)**

| MBTI     | Big Five A 得分 | 特征描述                               |
| -------- | --------------- | -------------------------------------- |
| F (情感) | 高分 (45-60)    | 重视和谐、考虑他人感受、合作、同情心强 |
| T (思考) | 低分 (12-30)    | 重视逻辑、客观分析、直接、竞争性强     |

**说明**:

- F 型与高宜人性相关，都重视人际关系和他人感受
- T 型与低宜人性相关，更注重逻辑和客观标准
- 但 T/F 主要是决策方式，A 主要是人际倾向，有区别

---

### 4. J/P (判断 - 知觉) ↔ C (尽责性)

**映射强度：强相关 (r ≈ 0.6-0.7)**

| MBTI     | Big Five C 得分 | 特征描述                               |
| -------- | --------------- | -------------------------------------- |
| J (判断) | 高分 (45-60)    | 有计划、有条理、提前完成、注重截止日期 |
| P (知觉) | 低分 (12-30)    | 灵活、随性、最后一刻完成、适应变化     |

**说明**:

- J 型与高尽责性高度相关，都喜欢结构和计划
- P 型与低尽责性相关，更灵活和自发
- 但 J/P 还涉及对确定性的偏好，不完全等同于尽责性

---

### 5. N (神经质) 的对应

**MBTI 中没有直接对应的维度**

Big Five 的 N (神经质) 维度在 MBTI 中没有直接对应，但与以下方面有关：

- **情绪稳定性**: 影响所有 MBTI 类型的表现
- **压力反应**: 高 N 者在压力下可能表现出非典型行为
- **类型发展**: 高 N 可能阻碍个体发展其偏好的认知功能

**建议**: 在 Persona Lab 中，N 得分可作为"类型确定性"的参考：

- 高 N + 维度得分接近 → 类型判断需谨慎
- 低 N + 维度得分明显 → 类型判断更可靠

## Phase 0 标定策略

### 数据采集

1. **同时测量**: Phase 0 同时采集 Big Five (IPIP-NEO-60) 和 MBTI 四维度 (中文补充题) 数据
2. **交叉验证**: 比较 E-I、O-S、A-T、C-J 的对应关系一致性
3. **识别异常**: 映射关系严重不一致的样本需进一步审查

### 类型推断算法 (建议)

```python
def infer_mbti_type(big5_scores, mbti_scores):
    """
    基于 Big Five 和 MBTI 补充题得分推断 MBTI 类型

    big5_scores: {'O': x, 'C': x, 'E': x, 'A': x, 'N': x}
    mbti_scores: {'EI': x, 'SN': x, 'TF': x, 'JP': x}
    """
    # E/I: 优先使用 MBTI 补充题，Big Five E 作为验证
    ei_score = mbti_scores['EI']
    ei_confidence = 'E' if ei_score > 0 else 'I'

    # S/N: 结合 MBTI 补充题和 Big Five O
    sn_combined = mbti_scores['SN'] * 0.6 + (30 - big5_scores['O']) * 0.4
    sn_confidence = 'S' if sn_combined > 0 else 'N'

    # T/F: 结合 MBTI 补充题和 Big Five A
    tf_combined = mbti_scores['TF'] * 0.6 + (30 - big5_scores['A']) * 0.4
    tf_confidence = 'T' if tf_combined > 0 else 'F'

    # J/P: 结合 MBTI 补充题和 Big Five C
    jp_combined = mbti_scores['JP'] * 0.6 + big5_scores['C'] * 0.4
    jp_confidence = 'J' if jp_combined > 0 else 'P'

    return f"{ei_confidence}{sn_confidence}{tf_confidence}{jp_confidence}"
```

### 置信度评估

| 指标                 | 高置信度 | 中置信度   | 低置信度       |
| -------------------- | -------- | ---------- | -------------- |
| 维度得分差           | >15 分   | 8-15 分    | <8 分          |
| Big Five-MBTI 一致性 | 4/4 一致 | 2-3/4 一致 | 0-1/4 一致     |
| 注意力检测           | 全对     | 错 1 题    | 错≥2 题 (无效) |
| 社会赞许性           | <3.5 分  | 3.5-4.5 分 | >4.5 分 (无效) |

## 注意事项

1. **相关性≠等同**: 映射关系基于统计相关，不是概念等同
2. **文化差异**: 中文语境下某些维度表现可能不同
3. **个体差异**: 同一 MBTI 类型内 Big Five 得分仍有变异
4. **发展变化**: 人格特质可随时间和经历变化
5. **情境影响**: 测试情境和动机影响作答
