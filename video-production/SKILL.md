# 视频制作技能体系

## 一、视频叙事结构

### 经典 5 秒短视频结构

| 时间段 | 目的                      | 手法                             |
| ------ | ------------------------- | -------------------------------- |
| 0-1s   | 抓注意力（Hook）          | 大字号标题 + 强烈视觉冲击 + 音效 |
| 1-2s   | 核心价值（Value）         | 一句话说明"这是什么"             |
| 2-3.5s | 差异化（Differentiation） | 2-3 个核心卖点，逐条出现         |
| 3.5-5s | 行动号召（CTA）           | 明确按钮 + 紧迫感                |

### 15 秒短视频结构

| 时间段 | 目的     | 内容                   |
| ------ | -------- | ---------------------- |
| 0-2s   | Hook     | 问题/痛点/悬念         |
| 2-5s   | 引入     | 产品/服务亮相          |
| 5-10s  | 演示     | 核心功能展示（2-3 个） |
| 10-13s | 社交证明 | 用户评价/数据          |
| 13-15s | CTA      | 行动号召 + 品牌标识    |

## 二、视觉设计原则

### 色彩系统

- **品牌主色**：#6b5bff（紫色）
- **辅助色**：#4a90e2（蓝）、#ff6b9d（粉）
- **中性色**：#1a1a2e（深背景）、#ffffff（文字）
- **渐变**：同色系渐变，避免跳跃色

### 排版层级

| 层级         | 字号    | 用途          |
| ------------ | ------- | ------------- |
| H1 标题      | 72-96px | 品牌名/主标题 |
| H2 副标题    | 36-48px | 价值主张      |
| Body 正文    | 24-32px | 功能描述      |
| Caption 标注 | 18-20px | 小字说明      |

### 构图原则

- **三分法**：关键元素放在交叉点
- **留白**：至少 30% 画面留白
- **对齐**：所有元素有明确的对齐线
- **对比**：大小/颜色/粗细制造视觉层次

## 三、动画与动效

### 缓动函数

```
ease-in-out: t² × (3 - 2t)  // 最常用，自然过渡
ease-out: 1 - (1-t)³        // 快速进入，缓慢停止
ease-in: t³                  // 缓慢进入，快速停止
bounce: 弹性效果
```

### 常用动画类型

| 动画          | 适用场景          | 时长     |
| ------------- | ----------------- | -------- |
| Fade In/Out   | 文字出现/消失     | 0.5-0.8s |
| Slide Up/Down | 列表项逐个出现    | 0.3-0.5s |
| Scale In      | Logo/标题强调     | 0.4-0.6s |
| Typewriter    | 代码/文字逐字出现 | 0.05s/字 |
| Pulse         | CTA 按钮呼吸效果  | 1s 循环  |
| Parallax      | 背景/前景差速移动 | 持续     |

### 动画原则

1. **同一时间最多 2 个动画**，避免视觉混乱
2. **动画时长 0.3-0.8s**，太短没感觉，太长拖沓
3. **用 ease-in-out**，线性动画看起来廉价
4. **元素逐个出现**，不要同时全部出现

## 四、音频设计

### BGM 选择原则

| 视频类型 | 音乐风格    | BPM     |
| -------- | ----------- | ------- |
| 科技感   | 电子/合成器 | 100-120 |
| 简约风   | 钢琴/原声   | 60-80   |
| 活力风   | 流行/电子   | 120-140 |
| 专业风   | 轻音乐/氛围 | 80-100  |

### 音效使用

- **文字出现**：轻微的 "whoosh" 或 "click"
- **CTA 按钮**：更明显的音效引导点击
- **转场**：过渡音效连接场景

### 音量平衡

- BGM：-20dB 到 -15dB（背景，不抢注意力）
- 配音：-6dB 到 -3dB（清晰可闻）
- 音效：-12dB（比 BGM 大，比配音小）

## 五、转场技巧

### 常用转场

| 转场           | 适用场景   | 时长 |
| -------------- | ---------- | ---- |
| Cross Dissolve | 场景切换   | 0.5s |
| Zoom In/Out    | 节奏变化   | 0.3s |
| Slide          | 时间线推进 | 0.4s |

## 六、FFmpeg 高级用法

### 文字动画

```bash
# 淡入文字
drawtext="text='Hello':x=(w-tw)/2:y=h-100:
  enable='between(t,0,2)':
  alpha='if(lt(t,0.5),t/0.5,1)'"

# 上滑文字
drawtext="text='Hello':x=(w-tw)/2:y=h-100*(1-t/1):
  enable='between(t,0,1)'"
```

### 转场效果

```bash
# Cross Dissolve
ffmpeg -i input1.mp4 -i input2.mp4 \
  -filter_complex "[0:v][1:v]xfade=transition=fade:duration=0.5:offset=4.5" \
  output.mp4
```

### 变速

```bash
# 前半段正常，后半段慢放
ffmpeg -i input.mp4 \
  -filter_complex "[0:v]setpts=if(lt(T,2.5),PTS,2*PTS+2.5*0.5)" \
  output.mp4
```

## 七、工作流程

### 标准流程

1. **脚本** → 确定内容、时长、节奏
2. **分镜** → 每 0.5-1 秒的画面描述
3. **素材** → 收集/生成图片、音乐、音效
4. **制作** → 用 FFmpeg/Pillow 逐帧生成
5. **合成** → FFmpeg 合成视频 + 音频
6. **审查** → 检查节奏、色彩、字幕
7. **输出** → H.264 + AAC，适配平台

### 检查清单

- [ ] 前 1 秒是否有视觉冲击？
- [ ] 信息是否精简（5 秒内不超过 3 个信息点）？
- [ ] 动画是否流畅（ease-in-out，时长合理）？
- [ ] 色彩是否统一（品牌色为主）？
- [ ] 文字是否可读（对比度足够，字号够大）？
- [ ] 是否有明确的 CTA？
- [ ] 是否有 BGM 和音效？
- [ ] 整体节奏是否紧凑？

## 八、专业视频制作核心原则

### 8.1 视觉冲击（前 1 秒决定生死）

**原则：前 1 秒必须抓住注意力**

- 用大字号（≥72px）+ 高对比度（白字+深色背景）
- 避免渐进式出现，第一帧就要有内容
- 可以用几何图形/粒子效果制造视觉冲击
- 标题文字要短（≤6 个字），让人一眼看完

**错误示范**：渐变背景慢慢出现 + 小字淡入
**正确示范**：纯色背景 + 大标题直接出现 + 轻微缩放动画

### 8.2 信息密度控制

**原则：5 秒视频最多 3 个信息点**
| 时长 | 最多文字 | 说明 |
|------|---------|------|
| 5 秒 | ≤15 字 | 品牌名 + 一句话价值主张 |
| 15 秒 | ≤30 字 | 品牌名 + 2-3 个卖点 |
| 30 秒 | ≤50 字 | 品牌名 + 3-4 个卖点 + 社交证明 |

**关键**：每个信息点至少停留 1 秒，让观众有时间阅读

### 8.3 动画节奏感

**原则：动画要有节奏，不要同时发生**

- ✅ 正确：标题出现 → 0.3s 后副标题出现 → 0.3s 后卖点逐个出现
- ❌ 错误：所有元素同时淡入

**节奏模板**：

```
0.0s  标题出现（Scale In, 0.4s）
0.5s  副标题出现（Fade In, 0.5s）
1.0s  卖点 1 出现（Slide Up, 0.3s）
1.5s  卖点 2 出现（Slide Up, 0.3s）
2.0s  卖点 3 出现（Slide Up, 0.3s）
3.0s  CTA 出现（Scale In, 0.4s）
4.0s  CTA 开始 Pulse 动画
```

### 8.4 色彩运用

**原则：一个画面最多 3 种颜色**

- 主色（品牌色）：占 60%
- 辅助色（对比色）：占 30%
- 强调色（CTA/重点）：占 10%

**对比度检查**：

- 白字 + 深色背景：对比度 ≥ 7:1 ✅
- 灰字 + 深色背景：对比度 ≥ 4.5:1 ⚠️
- 浅色 + 浅色：对比度 < 3:1 ❌ 不可读

### 8.5 文案技巧

**5 秒视频文案公式**：

```
[品牌名] + [核心价值] + [行动号召]

示例：
"人格探索局" + "15 题发现你的 MBTI" + "立即开始"
```

**文案原则**：

- 用动词开头（发现/开始/了解）
- 用数字增加可信度（15 题/3 分钟/100 万人）
- 避免形容词（"最好的"、"最强的"）
- CTA 要明确（"立即开始" > "了解更多"）

## 九、FFmpeg 高级动画技巧

### 9.1 粒子效果（模拟）

```bash
# 使用 noise 滤镜模拟粒子背景
ffmpeg -f lavfi -i "color=c=black:s=1080x1920:d=5,
  geq=r='random(1)*255':g='random(1)*255':b='random(1)*255',
  scale=1080x1920:flags=lanczos,
  format=yuv420p" \
  -c:v libx264 -crf 20 particles.mp4
```

### 9.2 几何图形动画

```bash
# 使用 drawbox 绘制动态几何图形
ffmpeg -f lavfi -i "color=c=#1a1a2e:s=1080x1920:d=5,
  format=yuv420p,
  drawbox=x=440:y=860:w=200:h=200:c=#6b5bff@0.3:t=fill,
  drawbox=x=500:y=920:w=80:h=80:c=#6b5bff@0.5:t=fill" \
  -c:v libx264 -crf 18 shapes.mp4
```

### 9.3 多段视频合成

```bash
# 将多个片段合成，带转场
ffmpeg -i clip1.mp4 -i clip2.mp4 -i clip3.mp4 \
  -filter_complex "
    [0:v][1:v]xfade=transition=fade:duration=0.5:offset=4.5[v01];
    [v01][2:v]xfade=transition=slideleft:duration=0.5:offset=9.0[outv]
  " \
  -map "[outv]" -c:v libx264 output.mp4
```

### 9.4 音频混音

```bash
# 视频 + BGM + 配音
ffmpeg -i video.mp4 -i bgm.mp3 -i voice.mp3 \
  -filter_complex "
    [1:a]afade=t=in:st=0:d=1,volume=-20dB:bgm;
    [2:a]afade=t=in:st=0:d=0.5,volume=-6dB[voice];
    [bgm][voice]amix=inputs=2:duration=first:dropout_transition=0[aout]
  " \
  -map 0:v -map "[aout]" -c:v copy -c:a aac output.mp4
```

### 9.5 文字逐字出现（打字机效果）

```bash
# 使用 enable 控制文字逐字出现
ffmpeg -f lavfi -i "color=c=black:s=1080x1920:d=3,
  drawtext=text='Hello World':
    fontfile=/path/to/font.ttf:
    fontsize=48:fontcolor=white:
    x=(w-tw)/2:y=(h-th)/2:
    enable='between(t,0,3)':
    alpha='if(lt(t,1),t,1)'" \
  -c:v libx264 typewriter.mp4
```

## 十、常见错误与修复

### 10.1 视觉问题

| 错误       | 原因       | 修复                    |
| ---------- | ---------- | ----------------------- |
| 文字看不清 | 对比度不足 | 加阴影/描边，或换背景色 |
| 动画卡顿   | 帧率不足   | 确保 25fps 以上         |
| 颜色跳跃   | 色值不一致 | 使用 CSS 变量统一管理   |
| 画面拥挤   | 信息过多   | 删减文字，增加留白      |

### 10.2 节奏问题

| 错误          | 原因         | 修复             |
| ------------- | ------------ | ---------------- |
| 前 1 秒没内容 | 淡入太慢     | 第一帧就有内容   |
| 信息来不及看  | 停留太短     | 每个信息点 ≥1s   |
| 动画同时发生  | 时间线重叠   | 错开 0.3-0.5s    |
| 结尾太仓促    | CTA 出现太晚 | 至少留 1s 给 CTA |

### 10.3 技术问题

| 错误       | 原因         | 修复             |
| ---------- | ------------ | ---------------- |
| 视频模糊   | 分辨率太低   | 至少 1080p       |
| 文件太大   | 码率太高     | CRF 18-23 之间   |
| 无法播放   | 编码不兼容   | H.264 + AAC      |
| 竖屏变横屏 | 比例设置错误 | 1080x1920 (9:16) |

## 十二、实用工具链

```
素材获取 → 编辑制作 → 合成输出 → 平台发布
    ↓           ↓          ↓          ↓
 yt-dlp     Pillow      FFmpeg     各平台 API
 下载视频   生成帧      合成视频    自动发布
```

### 工具对比

| 工具    | 优势                   | 劣势                 | 适用场景             |
| ------- | ---------------------- | -------------------- | -------------------- |
| FFmpeg  | 功能强大，支持所有格式 | 命令行，学习曲线陡   | 视频合成、转码、滤镜 |
| Pillow  | Python 生态，易编程    | 无视频支持，只能逐帧 | 生成静态帧、图形     |
| MoviePy | Python 视频编辑        | 性能较差，功能有限   | 简单剪辑、字幕       |
| Whisper | 语音转文字准确         | 需要 GPU 加速        | 生成字幕             |
