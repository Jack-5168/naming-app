## 题目 1：最长公共前缀 (Longest Common Prefix)
**难度：** 简单  
**题号：** LeetCode 14

### 题目描述
编写一个函数来查找字符串数组中的最长公共前缀。如果不存在公共前缀，返回空字符串 ""。

### 解题思路
**水平扫描法：** 取第一个字符串作为基准，逐个字符与后续字符串对比。一旦发现不匹配，返回当前前缀。

**优化思路：** 可以先找出最短字符串，公共前缀不可能超过最短字符串的长度。

### 代码实现
```javascript
/**
 * @param {string[]} strs
 * @return {string}
 */
function longestCommonPrefix(strs) {
    if (strs.length === 0) return '';
    
    // 以第一个字符串为基准
    let prefix = strs[0];
    
    for (let i = 1; i < strs.length; i++) {
        // 当前字符串不以 prefix 开头时，缩短 prefix
        while (strs[i].indexOf(prefix) !== 0) {
            prefix = prefix.slice(0, -1);
            if (prefix === '') return '';
        }
    }
    
    return prefix;
}

// 测试用例
console.log(longestCommonPrefix(["flower", "flow", "flight"])); // "fl"
console.log(longestCommonPrefix(["dog", "racecar", "car"])); // ""
console.log(longestCommonPrefix(["interspecies", "interstellar", "interstate"])); // "inters"
console.log(longestCommonPrefix(["a"])); // "a"
console.log(longestCommonPrefix(["", "b"])); // ""
```

### 复杂度分析
- 时间复杂度：O(S)，S 为所有字符串字符总数。最坏情况下每个字符都被比较一次。
- 空间复杂度：O(1) — 只使用常数级额外空间。

### 关键技巧
- `indexOf(prefix) !== 0` 巧妙判断字符串是否以某前缀开头
- 逐步缩短前缀，避免逐字符比较的嵌套循环

## 题目 2：有效的字母异位词 (Valid Anagram)
**难度：** 简单  
**题号：** LeetCode 242

### 题目描述
给定两个字符串 s 和 t，编写一个函数来判断 t 是否是 s 的字母异位词。字母异位词指由相同字母重排列形成的字符串。

### 解题思路
**哈希表计数法：** 用长度为 26 的数组记录每个字母出现次数。s 中字符 +1，t 中字符 -1，最后检查数组是否全为 0。

**进阶思考：** 如果输入包含 Unicode 字符，可以用 Map 替代固定数组。

### 代码实现
```javascript
/**
 * @param {string} s
 * @param {string} t
 * @return {boolean}
 */
function isAnagram(s, t) {
    // 长度不同直接返回 false
    if (s.length !== t.length) return false;
    
    const count = new Array(26).fill(0);
    
    for (let i = 0; i < s.length; i++) {
        count[s.charCodeAt(i) - 97]++;  // 'a' = 97
        count[t.charCodeAt(i) - 97]--;
    }
    
    for (let i = 0; i < 26; i++) {
        if (count[i] !== 0) return false;
    }
    
    return true;
}

// 进阶版：支持 Unicode 字符
function isAnagramUnicode(s, t) {
    if (s.length !== t.length) return false;
    
    const map = new Map();
    
    for (const char of s) {
        map.set(char, (map.get(char) || 0) + 1);
    }
    
    for (const char of t) {
        if (!map.has(char)) return false;
        map.set(char, map.get(char) - 1);
        if (map.get(char) === 0) map.delete(char);
    }
    
    return map.size === 0;
}

// 测试用例
console.log(isAnagram("anagram", "nagaram")); // true
console.log(isAnagram("rat", "car")); // false
console.log(isAnagramUnicode("abc", "cba")); // true
console.log(isAnagramUnicode("a", "ab")); // false
```

### 复杂度分析
- 时间复杂度：O(n) — 遍历两个字符串各一次
- 空间复杂度：O(1) — 固定 26 长度数组 / O(k) — k 为不同字符数（Map 版）

### 关键技巧
- 字符 → 数组索引的映射：`charCodeAt(i) - 97`
- 先比较长度，快速排除不可能情况
- 固定数组 vs Map 的选择取决于字符集范围

## 题目 3：存在重复元素 (Contains Duplicate)
**难度：** 简单  
**题号：** LeetCode 217

### 题目描述
给你一个整数数组 nums。如果任一值在数组中出现至少两次，返回 true；如果数组中每个元素互不相同，返回 false。

### 解题思路
**Set 去重法：** 利用 Set 自动去重的特性，比较 Set 大小与原数组长度。

**排序法：** 先排序，然后检查相邻元素是否相等。

### 代码实现
```javascript
/**
 * @param {number[]} nums
 * @return {boolean}
 */
// 方法一：Set（推荐）
function containsDuplicate(nums) {
    return new Set(nums).size !== nums.length;
}

// 方法二：排序 + 相邻比较
function containsDuplicateSort(nums) {
    nums.sort((a, b) => a - b);
    for (let i = 0; i < nums.length - 1; i++) {
        if (nums[i] === nums[i + 1]) return true;
    }
    return false;
}

// 方法三：哈希表（早期退出）
function containsDuplicateMap(nums) {
    const seen = new Set();
    for (const num of nums) {
        if (seen.has(num)) return true;
        seen.add(num);
    }
    return false;
}

// 测试用例
console.log(containsDuplicate([1, 2, 3, 1])); // true
console.log(containsDuplicate([1, 2, 3, 4])); // false
console.log(containsDuplicate([1, 1, 1, 3, 3, 4, 3, 2, 4, 2])); // true
```

### 复杂度分析
- Set 方法：时间 O(n)，空间 O(n)
- 排序方法：时间 O(n log n)，空间 O(1) 或 O(log n)
- Map 早期退出：时间 O(n) 最好 O(1)，空间 O(n)

### 关键技巧
- Set 是最简洁的解法，但不会早期退出
- Map/手动 Set 可以在发现重复时立即返回，平均情况更快
- 排序法空间最优，适合内存受限场景

## 题目 4：字母异位词分组 (Group Anagrams)
**难度：** 中等  
**题号：** LeetCode 49

### 题目描述
给你一个字符串数组，将字母异位词组合在一起。可以按任意顺序返回结果。

### 解题思路
**排序键法：** 将每个字符串排序后的结果作为哈希表的 key，相同 key 的字符串归为一组。

**计数键法：** 统计每个字符出现次数，用计数数组的字符串形式作为 key。比排序法更高效。

### 代码实现
```javascript
/**
 * @param {string[]} strs
 * @return {string[][]}
 */
// 方法一：排序键（直观）
function groupAnagrams(strs) {
    const map = new Map();
    
    for (const str of strs) {
        const key = str.split('').sort().join('');
        if (!map.has(key)) {
            map.set(key, []);
        }
        map.get(key).push(str);
    }
    
    return Array.from(map.values());
}

// 方法二：计数键（更高效）
function groupAnagramsCount(strs) {
    const map = new Map();
    
    for (const str of strs) {
        const count = new Array(26).fill(0);
        for (let i = 0; i < str.length; i++) {
            count[str.charCodeAt(i) - 97]++;
        }
        // 用 "#" 分隔避免 "1,11" 和 "11,1" 冲突
        const key = count.join('#');
        
        if (!map.has(key)) {
            map.set(key, []);
        }
        map.get(key).push(str);
    }
    
    return Array.from(map.values());
}

// 测试用例
console.log(groupAnagrams(["eat", "tea", "tan", "ate", "nat", "bat"]));
// [["eat","tea","ate"],["tan","nat"],["bat"]]

console.log(groupAnagrams([""]));
// [[""]]

console.log(groupAnagrams(["a"]));
// [["a"]]

// 性能对比
const largeInput = Array(10000).fill("eat").concat(
    Array(10000).fill("tea"),
    Array(10000).fill("abc")
);
console.time('sort-key');
groupAnagrams(largeInput);
console.timeEnd('sort-key');

console.time('count-key');
groupAnagramsCount(largeInput);
console.timeEnd('count-key');
```

### 复杂度分析
- 排序键：时间 O(n × k log k)，k 为字符串最大长度
- 计数键：时间 O(n × k)，空间 O(n × k)

### 关键技巧
- 排序键 vs 计数键的权衡：代码简洁 vs 性能
- 计数键用 `#` 分隔符避免键冲突
- `Array.from(map.values())` 优雅地提取分组结果

## 题目 5：滑动窗口最大值 (Sliding Window Maximum)
**难度：** 中等  
**题号：** LeetCode 239

### 题目描述
给你一个整数数组 nums，有一个大小为 k 的滑动窗口从数组最左侧移动到最右侧。你只能看到窗口内的 k 个数字，窗口每次向右移动一位。返回滑动窗口中的最大值。

### 解题思路
**单调队列（双端队列）：** 维护一个递减的双端队列，队首始终是当前窗口的最大值。
- 新元素入队前，弹出所有小于它的元素（因为它们不可能成为最大值）
- 移除超出窗口范围的队首元素
- 队首元素即为当前窗口最大值

### 代码实现
```javascript
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number[]}
 */
function maxSlidingWindow(nums, k) {
    const result = [];
    const deque = []; // 存储索引，保持递减
    
    for (let i = 0; i < nums.length; i++) {
        // 移除超出窗口范围的队首元素
        if (deque.length > 0 && deque[0] === i - k) {
            deque.shift();
        }
        
        // 维护递减队列：弹出所有小于当前元素的后部元素
        while (deque.length > 0 && nums[deque[deque.length - 1]] <= nums[i]) {
            deque.pop();
        }
        
        deque.push(i);
        
        // 窗口形成后开始记录最大值
        if (i >= k - 1) {
            result.push(nums[deque[0]]);
        }
    }
    
    return result;
}

// 测试用例
console.log(maxSlidingWindow([1, 3, -1, -3, 5, 3, 6, 7], 3));
// [3, 3, 5, 5, 6, 7]

console.log(maxSlidingWindow([1], 1));
// [1]

console.log(maxSlidingWindow([1, -1], 1));
// [1, -1]

console.log(maxSlidingWindow([9, 11], 2));
// [11]

console.log(maxSlidingWindow([4, -2], 2));
// [4]
```

### 复杂度分析
- 时间复杂度：O(n) — 每个元素最多入队和出队各一次
- 空间复杂度：O(k) — 双端队列最多存储 k 个元素

### 关键技巧
- 单调队列是滑动窗口最值问题的标准解法
- 存储索引而非值，方便判断元素是否超出窗口
- `shift()` 操作在 JS 中是 O(n)，严格实现可用循环数组优化
