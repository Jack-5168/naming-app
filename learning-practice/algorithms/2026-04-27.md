## 题目 1：罗马数字转整数 (Roman to Integer)

**难度：** 简单  
**题号：** LeetCode 13

### 题目描述

罗马数字包含以下七种字符：I，V，X，L，C，D 和 M。

| 字符 | 数值 |
| ---- | ---- |
| I    | 1    |
| V    | 5    |
| X    | 10   |
| L    | 50   |
| C    | 100  |
| D    | 500  |
| M    | 1000 |

例如，罗马数字 2 写做 II，即为两个并列的 1。12 写做 XII，即为 X + II。27 写做 XXVII，即为 XX + V + II。

通常情况下，罗马数字中小的数字在大的数字的右边。但也存在特例，例如 4 不写做 IIII，而是 IV。数字 1 在数字 5 的左边，所表示的数等于大数 5 减小数 1 得到的数值 4。同样地，数字 9 表示为 IX。

给定一个罗马数字，将其转换成整数。

### 解题思路

**核心规律：** 遍历字符串，如果当前字符对应的数值 **小于** 右侧字符的数值，说明是减法规则（如 IV 中的 I），需要 **减去** 当前值；否则 **加上** 当前值。

**关键点：** 用哈希表（对象）建立字符到数值的映射，一次遍历即可完成。

### 代码实现

```javascript
/**
 * @param {string} s
 * @return {number}
 */
function romanToInt(s) {
  const romanMap = {
    I: 1,
    V: 5,
    X: 10,
    L: 50,
    C: 100,
    D: 500,
    M: 1000,
  };

  let result = 0;

  for (let i = 0; i < s.length; i++) {
    const current = romanMap[s[i]];
    const next = romanMap[s[i + 1]];

    // 如果当前值小于右侧值，说明是减法规则
    if (next && current < next) {
      result -= current;
    } else {
      result += current;
    }
  }

  return result;
}

// 测试用例
console.log(romanToInt("III")); // 3
console.log(romanToInt("IV")); // 4
console.log(romanToInt("IX")); // 9
console.log(romanToInt("LVIII")); // 58
console.log(romanToInt("MCMXCIV")); // 1994
console.log(romanToInt("CDXLIX")); // 449
```

### 复杂度分析

- 时间复杂度：O(n) — 遍历字符串一次，n 为字符串长度
- 空间复杂度：O(1) — 哈希表固定 7 个条目

### 关键技巧

- 罗马数字的减法规则本质上是「左小右大时相减」，不需要特殊处理 6 种特例
- 比较 `current` 和 `next` 的大小关系，统一处理加减逻辑
- 对象字面量 `{}` 作为哈希表，比 `Map` 更简洁（固定键集合）

## 题目 2：验证回文串 (Valid Palindrome)

**难度：** 简单  
**题号：** LeetCode 125

### 题目描述

给定一个字符串，验证它是否是回文串，只考虑字母和数字字符，可以忽略字母的大小写。

**说明：** 本题中，我们将空字符串定义为有效的回文串。

### 解题思路

**双指针法：** 左指针从头部开始，右指针从尾部开始，各自跳过非字母数字字符，然后比较对应位置的字符（统一转小写）。

**关键细节：**

- 使用 `charCodeAt()` 判断字符类型（数字 48-57，大写字母 65-90，小写字母 97-122）
- 统一转小写后比较，避免大小写问题

### 代码实现

```javascript
/**
 * @param {string} s
 * @return {boolean}
 */
function isPalindrome(s) {
  let left = 0;
  let right = s.length - 1;

  while (left < right) {
    // 左指针跳过非字母数字字符
    while (left < right && !isAlphanumeric(s[left])) {
      left++;
    }

    // 右指针跳过非字母数字字符
    while (left < right && !isAlphanumeric(s[right])) {
      right--;
    }

    // 比较字符（统一小写）
    if (s[left].toLowerCase() !== s[right].toLowerCase()) {
      return false;
    }

    left++;
    right--;
  }

  return true;
}

function isAlphanumeric(char) {
  const code = char.charCodeAt(0);
  return (
    (code >= 48 && code <= 57) || // 0-9
    (code >= 65 && code <= 90) || // A-Z
    (code >= 97 && code <= 122)
  ); // a-z
}

// 测试用例
console.log(isPalindrome("A man, a plan, a canal: Panama")); // true
console.log(isPalindrome("race a car")); // false
console.log(isPalindrome(" ")); // true
console.log(isPalindrome("0P")); // false
console.log(isPalindrome("Was it a car or a cat I saw?")); // true
```

### 复杂度分析

- 时间复杂度：O(n) — 每个字符最多被访问一次
- 空间复杂度：O(1) — 只使用两个指针

### 关键技巧

- 双指针是回文类问题的标准模式
- `isAlphanumeric` 用 ASCII 码范围判断，比正则更快
- 先跳过无效字符再比较，避免中间逻辑混乱

## 题目 3：只出现一次的数字 (Single Number)

**难度：** 简单  
**题号：** LeetCode 136

### 题目描述

给你一个 **非空** 整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

**要求：** 必须设计并实现线性时间复杂度的算法，且只使用常量额外空间。

### 解题思路

**异或运算（XOR）：** 利用异或运算的性质：

- `a ^ a = 0`（相同数字异或为 0）
- `a ^ 0 = a`（任何数与 0 异或等于自身）
- 异或满足交换律和结合律

因此，将所有数字异或一遍，出现两次的数字互相抵消为 0，剩下的就是只出现一次的数字。

**对比方案：** 哈希表需要 O(n) 空间，排序需要 O(n log n) 时间，都不满足题目要求。

### 代码实现

```javascript
/**
 * @param {number[]} nums
 * @return {number}
 */
function singleNumber(nums) {
  let result = 0;
  for (const num of nums) {
    result ^= num;
  }
  return result;
}

// 测试用例
console.log(singleNumber([2, 2, 1])); // 1
console.log(singleNumber([4, 1, 2, 1, 2])); // 4
console.log(singleNumber([1])); // 1
console.log(singleNumber([0, 1, 0])); // 1

// 扩展：如果有一个数字出现一次，其余出现三次？
// 位计数法：统计每一位上 1 的出现次数，对 3 取模
function singleNumberIII(nums) {
  let result = 0;
  for (let i = 0; i < 32; i++) {
    let count = 0;
    for (const num of nums) {
      count += (num >> i) & 1;
    }
    if (count % 3 !== 0) {
      result |= 1 << i;
    }
  }
  return result;
}

console.log(singleNumberIII([2, 2, 3, 2])); // 3
console.log(singleNumberIII([0, 1, 0, 1, 0, 1, 99])); // 99
```

### 复杂度分析

- 时间复杂度：O(n) — 遍历数组一次
- 空间复杂度：O(1) — 只用一个变量

### 关键技巧

- 异或运算是「成对消除」问题的终极武器
- 位运算技巧：`>>` 右移取位，`& 1` 取最低位，`|=` 设置位
- 扩展题（出现三次）用位计数法，思路完全不同

## 题目 4：两数之和 II — 输入有序数组 (Two Sum II)

**难度：** 中等  
**题号：** LeetCode 167

### 题目描述

给你一个下标从 1 开始的整数数组 `numbers`，该数组已按 **非递减顺序** 排列，请你从数组中找出满足相加之和等于目标数 `target` 的两个数。返回这两个数的下标值 `index1` 和 `index2`（1-based）。

**约束：** 每个输入只对应唯一的答案，不能重复使用相同元素，解决方案必须只使用常量级额外空间。

### 解题思路

**双指针法：** 因为数组已排序，左指针指向最小值，右指针指向最大值。

- 和小于 target → 左指针右移（增大和）
- 和大于 target → 右指针左移（减小和）
- 和等于 target → 找到答案

**对比：** 无序数组用哈希表（O(n) 空间），有序数组用双指针（O(1) 空间），排序是核心前提。

### 代码实现

```javascript
/**
 * @param {number[]} numbers
 * @param {number} target
 * @return {number[]}
 */
function twoSum(numbers, target) {
  let left = 0;
  let right = numbers.length - 1;

  while (left < right) {
    const sum = numbers[left] + numbers[right];

    if (sum === target) {
      return [left + 1, right + 1]; // 1-based
    } else if (sum < target) {
      left++; // 需要更大的和
    } else {
      right--; // 需要更小的和
    }
  }

  return []; // 理论上不会到达这里
}

// 测试用例
console.log(twoSum([2, 7, 11, 15], 9)); // [1, 2]
console.log(twoSum([2, 3, 4], 6)); // [1, 3]
console.log(twoSum([-1, 0], -1)); // [1, 2]
console.log(twoSum([1, 2, 3, 4, 4, 9, 56, 90], 8)); // [3, 5]

// 扩展：三数之和（LeetCode 15）
function threeSum(nums) {
  nums.sort((a, b) => a - b);
  const result = [];

  for (let i = 0; i < nums.length - 2; i++) {
    // 跳过重复
    if (i > 0 && nums[i] === nums[i - 1]) continue;

    let left = i + 1;
    let right = nums.length - 1;

    while (left < right) {
      const sum = nums[i] + nums[left] + nums[right];

      if (sum === 0) {
        result.push([nums[i], nums[left], nums[right]]);
        // 跳过重复
        while (left < right && nums[left] === nums[left + 1]) left++;
        while (left < right && nums[right] === nums[right - 1]) right--;
        left++;
        right--;
      } else if (sum < 0) {
        left++;
      } else {
        right--;
      }
    }
  }

  return result;
}

console.log(threeSum([-1, 0, 1, 2, -1, -4]));
// [[-1, -1, 2], [-1, 0, 1]]
```

### 复杂度分析

- 时间复杂度：O(n) — 双指针最多遍历一次
- 空间复杂度：O(1) — 只使用两个指针

### 关键技巧

- 有序数组 + 两数之和 = 双指针，这是标准模式
- 1-based 索引记得 `+1`
- 扩展的三数之和是「固定一个 + 双指针找两个」的组合模式
- 去重是进阶题的关键细节

## 题目 5：和为 K 的子数组 (Subarray Sum Equals K)

**难度：** 中等  
**题号：** LeetCode 560

### 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回该数组中和为 `k` 的子数组的个数。

子数组是数组中元素的连续非空序列。

### 解题思路

**前缀和 + 哈希表：** 核心公式是 `prefix[j] - prefix[i] = k`，即 `prefix[i] = prefix[j] - k`。

遍历时维护当前前缀和，用哈希表记录每个前缀和出现的次数。对于当前位置，检查 `prefixSum - k` 在哈希表中出现过几次，就找到了几个满足条件的子数组。

**为什么比暴力法好？** 暴力法 O(n²) 枚举所有子数组，前缀和 + 哈希表只需一次遍历 O(n)。

**边界处理：** 初始化 `map.set(0, 1)`，处理从数组开头就满足条件的子数组。

### 代码实现

```javascript
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
function subarraySum(nums, k) {
  const map = new Map();
  // 关键：前缀和为 0 出现 1 次（处理从索引 0 开始的子数组）
  map.set(0, 1);

  let prefixSum = 0;
  let count = 0;

  for (const num of nums) {
    prefixSum += num;

    // 检查是否存在前缀和为 (prefixSum - k) 的位置
    if (map.has(prefixSum - k)) {
      count += map.get(prefixSum - k);
    }

    // 记录当前前缀和的出现次数
    map.set(prefixSum, (map.get(prefixSum) || 0) + 1);
  }

  return count;
}

// 测试用例
console.log(subarraySum([1, 1, 1], 2)); // 2
console.log(subarraySum([1, 2, 3], 3)); // 2
console.log(subarraySum([1, -1, 0], 0)); // 3
console.log(subarraySum([1, 2, 1, 2, 1], 3)); // 4

// 对比：暴力法（O(n²)，用于理解问题）
function subarraySumBrute(nums, k) {
  let count = 0;
  for (let i = 0; i < nums.length; i++) {
    let sum = 0;
    for (let j = i; j < nums.length; j++) {
      sum += nums[j];
      if (sum === k) count++;
    }
  }
  return count;
}

console.log(subarraySumBrute([1, 1, 1], 2)); // 2
console.log(subarraySumBrute([1, 2, 1, 2, 1], 3)); // 4
```

### 复杂度分析

- 时间复杂度：O(n) — 一次遍历，Map 操作 O(1)
- 空间复杂度：O(n) — 哈希表最多存储 n 个不同前缀和

### 关键技巧

- **前缀和 + 哈希表** 是子数组求和问题的标准模式
- `map.set(0, 1)` 初始化是常见陷阱，不能遗漏
- 核心公式：`prefix[j] - prefix[i] = k` → 找 `prefix[i] = prefix[j] - k`
- 与「两数之和」思路一致：都是「用哈希表找补数」

### 双指针模式（本次重点）

1. **对撞指针** — 左右向中间靠拢（回文验证、两数之和 II）
2. **快慢指针** — 同向不同速（去重、链表操作）
3. **滑动窗口** — 维护一个窗口（上次的滑动窗口最大值）

### 哈希表模式（持续强化）

1. **映射模式** — 字符到数值的固定映射（罗马数字）
2. **计数模式** — 统计频率（上次的异位词分组）
3. **查找模式** — 找补数/找存在（两数之和 II 的无序版、子数组和为 K）
4. **分组模式** — 按特征归类（上次的字母异位词分组）

### 位运算初探

- 异或的三大性质：自反性、零元性、交换结合律
- `a ^ a = 0` 是「成对消除」的数学基础
- 位计数法可以推广到「出现 N 次」的通用问题

### 前缀和模式（新引入）

- 核心思想：`sum[i..j] = prefix[j] - prefix[i-1]`
- 配合哈希表，将 O(n²) 的子数组枚举降为 O(n)
- 初始化 `map.set(0, 1)` 是处理「从开头开始」的边界情况
