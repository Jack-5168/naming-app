## 📋 项目概述

人格探索局是一款基于 MBTI 理论的人格测试产品，核心差异化是**人格稳定性指数**——让用户知道自己的性格有多稳定，而不仅仅是标签。

**产品定位**：不是被定义，而是被理解  
**开发周期**：25 周（约 6 个月）  
**团队规模**：3-4 人（产品 + 前端 + 后端×2）  
**目标用户**：18-35 岁，自我探索需求人群

**题库构成**：

- IPIP-NEO 简化版：60 题（公有领域，大五人格）
- 中文补充题：100-150 题（原创，MBTI 维度）
- 测谎题/一致性检验：10-15 题（原创）
- **总计**：170-225 题

**验收标准**：

- [ ] IPIP 题目来源标注清晰
- [ ] 大五→MBTI 映射算法有学术依据
- [ ] 映射准确性验证（与经典测试对比一致性>75%）
- [ ] 被试数量 N≥500
- [ ] 重测信度 >0.75
- [ ] Cronbach's α >0.8
- [ ] 题目区分度 >0.8
- [ ] 版权合规文档完整

## 🎯 验收流程

### 代码验收

1. **代码审查**：Git 仓库审查（规范、注释、测试）
2. **功能测试**：按验收标准逐项测试
3. **性能测试**：压力测试（并发 100 QPS）
4. **安全测试**：OWASP Top 10 扫描

### 文档验收

1. **完整性**：所有交付物齐全
2. **准确性**：数据准确、无错误
3. **可读性**：结构清晰、易于理解
4. **可追溯**：版本历史完整

### 验收会议

- **频率**：每阶段结束前 1 周
- **参与人**：主代理、娄总、子代理负责人
- **议程**：
  1. 子代理演示交付物
  2. 主代理验收评审
  3. 娄总最终确认
  4. 问题清单 + 修复计划
