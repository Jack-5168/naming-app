## 1. 产品定位与愿景

### 1.1 产品定位

> **不是"算命工具"，而是"自我探索的陪伴者"**

一款基于塔罗牌的心理健康与自我认知小程序，帮助用户在迷茫时获得思考的视角，在焦虑时获得内心的平静。

### 1.2 愿景

成为年轻人首选的**心灵成长伴侣**，让每一次抽牌都成为一次有意义的自我对话。

### 1.3 差异化定位

| 维度 | 传统塔罗产品 | 本产品 |
|------|-------------|--------|
| 核心价值 | 预测未来 | 理解当下 |
| 内容风格 | 神秘主义 | 温暖治愈 |
| 交互方式 | 直接抽牌 | 仪式感引导 |
| 结果呈现 | 一次性解读 | 持续追踪 |
| 社交属性 | 分享结果 | 分享状态 |

### 1.4 合规声明

**重要**：本产品定位为"心理健康/自我探索工具"，非算命/占卜服务。

**免责声明**（首次使用前强制阅读）：
> "本内容仅供娱乐参考和自我探索，不构成专业心理建议或预测。如有严重心理问题，请咨询专业心理咨询师。"

## 2. 目标用户

### 2.1 核心用户画像

#### 👤 用户 A：探索型（25 岁，女性，一线城市白领）

**特征**：
- 工作压力大，经常感到迷茫
- 对心理学、自我成长感兴趣
- 愿意为精神消费付费
- 喜欢有质感的产品

**使用场景**：
- 早晨通勤路上抽每日单牌
- 面临选择时做三牌阵
- 睡前记录塔罗日记

**核心需求**：
- 获得心理安慰
- 找到思考问题的新视角
- 记录情绪变化

#### 👤 用户 B：好奇型（22 岁，女性，大学生）

**特征**：
- 对神秘学感兴趣
- 社交活跃，喜欢分享
- 价格敏感
- 容易被视觉吸引

**使用场景**：
- 和朋友一起抽牌玩
- 看到好看的牌面想分享
- 感情问题求助

**核心需求**：
- 娱乐消遣
- 社交货币
- 情感寄托

#### 👤 用户 C：成长型（28 岁，男性，互联网从业者）

**特征**：
- 理性思维，但愿意尝试新视角
- 面临职业/感情选择困惑

- 愿意为高质量内容付费

- 重大决策前做深度牌阵

**核心需求**：
- 获得决策参考

**特征**：
- 长期塔罗爱好者
- 有一定塔罗知识基础

## 6. 详细功能说明

### 6.1 每日单牌（P0）

#### 功能描述
用户每天可以免费抽取一张牌，获得当日的指引和建议。

#### 用户流程
```
1. 进入首页 → 点击"今日单牌"
2. 呼吸引导动画（根据使用次数智能显示/跳过）
3. 牌堆展示 → 滑动选牌
4. 翻牌动画 → 展示牌面
5. 分层解读展示
6. 保存到日记/分享
```

#### 界面元素
- 牌堆动画区域
- 呼吸引导提示（智能化）
- 牌面展示区（可翻转）
- 解读内容区（分层展开）
- 操作按钮（保存/分享/再抽一次）

#### 业务规则
- 每日 0 点刷新
- 可消耗会员次数额外抽牌
- 历史牌面可在日记中查看
- **抽牌结果由后端生成**（防篡改）

---

### 6.2 三牌阵（P0）

#### 功能描述
经典的过去 - 现在 - 未来三牌阵，适合解答具体问题。

#### 用户流程
```
1. 选择牌阵 → 三牌阵
2. 输入问题（引导式输入）
   - 问题分类（感情/事业/成长/其他）
   - 问题描述（可选）
3. 呼吸引导（可跳过）
4. 抽取三张牌
5. 逐张解读 + 整体解读
6. 保存/分享
```

#### 付费转化触点
- **第 3 次使用时**：弹出"今日免费次数已用完"提示
- 附带会员权益介绍（周卡¥9.9/月卡¥29）
- 一键开通，继续抽牌

#### 界面元素
- 问题输入表单
- 三牌阵布局（横向/纵向可选）
- 每张牌的独立解读区
- 牌与牌之间的关系说明
- 整体建议区

#### 业务规则
- 免费用户每日限用 3 次
- 会员无限次
- 问题历史可追溯
- **抽牌结果由后端生成**

---

### 6.3 快速抽牌（P1，新增）

#### 功能描述
跳过所有仪式，直接抽牌看结果，满足用户情绪激动时快速寻求指引的需求。

#### 入口位置
- 首页顶部常驻入口
- 标识："急需指引？快速抽牌"

#### 功能特点
- 无呼吸引导
- 无问题输入（可选填）
- 直接展示牌面 + 解读
- 事后仍可补充心情记录和备注

## 12. 风险与应对

### 12.1 政策风险（高）

**风险**：微信小程序对"塔罗/占卜"类目审核极严，可能被判为"封建迷信"拒绝上架

**应对措施**：
1. **定位包装**：强调"心理健康/自我探索"，避免"预测""算命"等词汇
2. **两套 UI 方案**：
   - 审核版：弱化塔罗元素，强化心理测试属性
   - 上线版：完整版体验
3. **资质准备**：准备企业资质，咨询心理咨询相关资质需求
4. **备用主体**：准备 2-3 个备用小程序上架主体

### 12.2 内容风险（中）

**风险**：解读内容被用户质疑"不准"，产生投诉

**应对措施**：
1. **显著免责声明**：首次使用前强制阅读，支付页再次提示
2. **内容审核机制**：所有解读文案经过专业审核
3. **用户反馈渠道**：提供内容反馈入口，及时响应用户疑虑
4. **客服工单系统**：Phase 2 建立完善的退款/纠纷处理流程

### 12.3 竞争风险（中）

**风险**：市场上已有类似产品（塔罗测测、神秘塔罗等）

**应对措施**：
1. **差异化定位**：自我探索 vs 算命，温暖治愈 vs 神秘主义
2. **体验优势**：仪式感设计、塔罗日记、周期回顾
3. **内容质量**：专业内容团队，保证解读质量
4. **快速迭代**：根据用户反馈快速优化

### 12.4 技术风险（中）

**风险**：动画性能问题、数据库性能瓶颈

**应对措施**：
1. **早期性能测试**：Week 3 开始真机性能基线测试
2. **动画降级方案**：低端机自动降级，提供"省电模式"
3. **数据库规划**：索引设计、分片策略、归档机制
4. **监控体系前置**：Phase 1 接入 Sentry + ARMS

### 12.5 商业风险（高）

**风险**：CAC/LTV 不健康，付费转化率低于预期

**应对措施**：
1. **MVP 验证**：Phase 1 上线后 2 周验证核心假设
2. **灵活调整**：如 7 日留存<30% 或付费转化<3%，重新思考价值主张
3. **多元收入**：会员 + 单次 + 虚拟商品 + B 端
4. **冷启动优先**：先做免费渠道验证，再考虑付费广告
