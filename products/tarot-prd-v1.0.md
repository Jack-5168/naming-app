## 1. 产品定位与愿景

### 1.1 产品定位

> **不是"算命工具"，而是"自我探索的陪伴者"**

一款基于塔罗牌的心理健康与自我认知小程序，帮助用户在迷茫时获得思考的视角，在焦虑时获得内心的平静。

### 1.2 愿景

成为年轻人首选的**心灵成长伴侣**，让每一次抽牌都成为一次有意义的自我对话。

### 1.3 差异化定位

| 维度 | 传统塔罗产品 | 本产品 |
|------|-------------|--------|
| 核心价值 | 预测未来 | 理解当下 |
| 内容风格 | 神秘主义 | 温暖治愈 |
| 交互方式 | 直接抽牌 | 仪式感引导 |
| 结果呈现 | 一次性解读 | 持续追踪 |
| 社交属性 | 分享结果 | 分享状态 |

## 6. 详细功能说明

### 6.1 每日单牌（P0）

#### 功能描述
用户每天可以免费抽取一张牌，获得当日的指引和建议。

#### 用户流程
```
1. 进入首页 → 点击"今日单牌"
2. 呼吸引导动画（3 次，可跳过）
3. 牌堆展示 → 滑动选牌
4. 翻牌动画 → 展示牌面
5. 分层解读展示
6. 保存到日记/分享
```

#### 界面元素
- 牌堆动画区域
- 呼吸引导提示
- 牌面展示区（可翻转）
- 解读内容区（分层展开）
- 操作按钮（保存/分享/再抽一次）

#### 业务规则
- 每日 0 点刷新
- 可消耗会员次数额外抽牌
- 历史牌面可在日记中查看

---

### 6.2 三牌阵（P0）

#### 功能描述
经典的过去 - 现在 - 未来三牌阵，适合解答具体问题。

#### 用户流程
```
1. 选择牌阵 → 三牌阵
2. 输入问题（引导式输入）
   - 问题分类（感情/事业/成长/其他）
   - 问题描述（可选）
3. 呼吸引导
4. 抽取三张牌
5. 逐张解读 + 整体解读
6. 保存/分享
```

#### 界面元素
- 问题输入表单
- 三牌阵布局（横向/纵向可选）
- 每张牌的独立解读区
- 牌与牌之间的关系说明
- 整体建议区

#### 业务规则
- 免费用户每日限用 3 次
- 会员无限次
- 问题历史可追溯

## 7. 用户体验设计

### 7.1 视觉风格

#### 色彩方案
```
主色调：
- 深空紫：#2D1B4E（品牌色，用于主背景）
- 月光金：#D4AF37（强调色，用于按钮/高亮）
- 星云蓝：#6B5B95（辅助色）

辅助色：
- 温暖白：#F8F6F0（文字）
- 暮色灰：#4A4A4A（次要文字）

渐变：
- 夜空渐变：深空紫 → 星云蓝
```

#### 字体选择
```
标题：思源宋体（有质感）
正文：思源黑体（易读）
英文：Playfair Display（牌名）
```

### 7.2 交互动画

#### 关键动画列表

| 动画 | 时长 | 缓动 | 说明 |
|------|------|------|------|
| 牌堆洗牌 | 1.5s | ease-in-out | 3D 翻转效果 |
| 选牌高亮 | 0.3s | ease-out | 触摸反馈 |
| 翻牌动画 | 0.8s | cubic-bezier | 3D 翻转 |
| 解读展开 | 0.4s | ease-out | 内容渐显 |
| 页面切换 | 0.3s | ease-in-out | 滑动过渡 |

#### 动画原则
- 有物理感（惯性、弹性）
- 不打断用户节奏
- 关键操作有反馈
- 可关闭（设置中）

### 7.3 仪式感设计

#### 抽牌前仪式
```
1. 环境准备
   - 背景音：轻柔的白噪音/冥想音乐
   - 视觉：粒子动画汇聚

2. 呼吸引导
   - 动画：圆圈扩张/收缩
   - 提示："吸气... 呼气..."
   - 次数：3 次

3. 问题聚焦
   - 引导语："静下心来，想着你的问题"
   - 倒计时：5 秒静默
```

#### 抽牌后仪式
```
1. 牌面展示
   - 缓慢浮现
   - 光效点缀

2. 解读呈现
   - 分层展开
   - 每层间隔 0.5s

3. 结束引导
   - "这条指引，你想如何践行？"
   - 引导记录/分享
```

{

    upright: [String],

    general: String,

## 12. 风险与应对

### 12.1 政策风险

**风险**：微信小程序对"算命/占卜"类目的审核限制

**应对**：
- 定位为"心理健康/自我探索"
- 避免"预测未来"等话术
- 准备备用上架主体

### 12.2 内容风险

**风险**：解读内容被用户质疑"不准"

**应对**：
- 明确免责声明
- 强调"参考"而非"定论"
- 提供内容反馈渠道

### 12.3 竞争风险

**风险**：市场上已有类似产品

**应对**：
- 差异化定位（自我探索 vs 算命）
- 更好的视觉和体验
- 持续的内容迭代

### 12.4 技术风险

**风险**：动画性能问题影响体验

**应对**：
- 早期性能测试
- 低端机适配
- 提供"简化动画"选项
