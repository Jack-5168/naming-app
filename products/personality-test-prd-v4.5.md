## 🧪 三、测评设计（v4.5 优化）

### 3.1 IRT 模型选择（修正）

**v4.4**：3PL（三参数逻辑模型）  
**v4.5**：**2PL MIRT（多维双参数逻辑模型）**

**变更原因**：

- 3PL 包含猜测参数 (c)，适用于能力测试（有对错之分）
- 人格测试无"正确答案"，猜测参数无理论意义
- MIRT 可同时建模四个维度，更符合 MBTI 结构

**2PL 模型公式**：

```
P(θ) = 1 / (1 + e^(-a(θ - b)))
```

其中：

- a = 区分度参数（discrimination）
- b = 难度参数（difficulty）
- θ = 能力参数（人格特质强度）

### 3.2 题库规模（扩展）

| 维度     | v4.4   | v4.5           | 理由                   |
| -------- | ------ | -------------- | ---------------------- |
| 总题库   | 200 题 | **300-400 题** | 每维度需 40 题保证精度 |
| E-I 维度 | ~50 题 | **75-100 题**  | 外向性是最常测维度     |
| N-S 维度 | ~50 题 | **75-100 题**  | -                      |
| T-F 维度 | ~50 题 | **75-100 题**  | -                      |
| J-P 维度 | ~50 题 | **75-100 题**  | -                      |

### 3.3 题目参数标定（新增流程）

```
Phase 0（Week 1-4）：题目参数标定预研究

步骤 1：招募预测试被试 N≥500
• 渠道：心理学社群/大学生样本
• 激励：免费完整报告 + ¥10 红包

步骤 2：完整测试（300 题）
• 时长：约 20-25 分钟
• 目的：收集题目反应数据

步骤 3：IRT 参数标定
• 方法：边际最大似然估计（MMLE）
• 工具：R 包 mirt 或 Python pyirt
• 输出：每道题的 a（区分度）和 b（难度）参数

步骤 4：题目筛选
• 删除区分度<0.8 的题目
• 删除难度极端（b>2 或 b<-2）的题目
• 保留 200-250 道高质量题目用于 CAT

决策点：
• 若标定后题目<150 道：补充题目重新标定
• 若重测信度<0.75：重新审视题目质量
```

### 3.4 测谎题/一致性检验（新增）

```
题目示例：
"我从不撒谎" → 社会赞许性检测
"有时我感到厌烦" → 反向计分检测
前后一致性题 → 同一维度不同表述题目对比

处理逻辑：
• 社会赞许性过高：提示"请根据真实情况作答"
• 一致性过低：结果页提示"本次测试置信度较低，建议重测"
```

## 💡 十、核心原则（v4.5 新增）

### 1. 科学第一，坦诚沟通

```
• MBTI 有争议 → 主动告知用户
• 测试有局限 → 明确说明
• 结果非诊断 → 多次强调
• 数据要保护 → 加密 + 透明
```

### 2. 用户体验优先

```
• 付费点前置 → 建立预期
• 连续谱呈现 → 避免标签化
• 分层解锁 → 降低门槛
• 仪式感设计 → 提升分享
```

### 3. 数据驱动决策

```
• 5 个关键实验 → 验证核心假设
• A/B 测试 → 优化转化
• 指标不达标 → 迭代或砍掉
• 财务预期 → 下调至现实
```

### 4. 伦理合规底线

```
• 知情同意 → 必填
• 免责声明 → 每页
• 心理援助 → 热线信息
• 数据删除 → 用户权利
```
