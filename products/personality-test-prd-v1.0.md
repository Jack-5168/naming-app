## 1. 市场分析与机会

### 1.1 市场规模

**心理测试赛道数据**：

- 微信小程序心理测试类 DAU 总量：500 万+
- 头部产品（如"心理测试中心"）DAU：50 万+
- 平均付费转化率：8-12%（高于塔罗类产品）
- 用户年复购率：65%（测试完一个还想测另一个）

**热门测试类型**：
| 类型 | 占比 | 爆款概率 | 变现能力 |
|------|------|---------|---------|
| MBTI 人格 | 35% | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| 爱情心理 | 25% | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 职业测评 | 15% | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 心理健康 | 10% | ⭐⭐⭐ | ⭐⭐⭐ |
| 趣味测试 | 15% | ⭐⭐⭐⭐⭐ | ⭐⭐ |

### 1.2 竞品分析

#### 头部竞品

| 产品          | DAU    | 核心优势         | 弱点             |
| ------------- | ------ | ---------------- | ---------------- |
| 心理测试中心  | 50 万+ | 测试库全（200+） | 体验粗糙，广告多 |
| MBTI 官方测评 | 30 万+ | 品牌认知强       | 价格高（¥99）    |
| 壹心理        | 20 万+ | 专业背书         | 功能复杂，像商城 |
| 简单心理      | 15 万+ | 心理咨询转化     | 测试是引流工具   |

#### 市场机会

1. **体验升级**：现有产品普遍 UI 老旧、广告干扰严重
2. **年轻化表达**：95 后/00 后偏好视觉化、社交化的测试结果
3. **价格带空白**：¥9.9-29 区间缺乏高质量测试
4. **社交裂变弱**：现有产品分享率低（<10%），有优化空间

### 1.3 成功要素

**爆款测试的 4 个特征**：

1. **低门槛**：5-10 分钟完成，题目≤30 道
2. **高共鸣**：结果描述让用户觉得"好准！"
3. **强社交**：结果天然适合分享（身份标签/对比/好奇）
4. **可行动**：给出具体建议，不是空泛描述

## 2. 产品定位与愿景

### 2.1 产品定位

> **"认识自己，从一次测试开始"**

一款面向年轻人的**人格探索与心理成长**小程序，用科学有趣的测试帮助用户理解自己、改善关系、规划成长。

### 2.2 愿景

成为年轻人首选的**自我认知工具**，让心理学知识触手可及。

### 2.3 差异化定位

| 维度     | 传统心理测试      | 本产品              |
| -------- | ----------------- | ------------------- |
| 内容风格 | 学术化/娱乐化两极 | 专业但易懂          |
| 结果呈现 | 大段文字          | 视觉化 + 可操作建议 |
| 社交属性 | 分享结果图        | 互动对比 + 话题引导 |
| 商业模式 | 广告 + 高价咨询   | 测试解锁 + 会员订阅 |
| 用户体验 | 做题→结果→结束    | 测试→解读→行动→追踪 |

## 3. 目标用户

### 3.1 核心用户画像

#### 👤 用户 A：自我探索型（24 岁，女性，一线城市白领）

**特征**：

- 对心理学感兴趣，关注自我成长
- 经常做各类测试（MBTI、九型人格等）
- 愿意为高质量内容付费
- 喜欢分享测试结果到朋友圈

**使用场景**：

- 刷朋友圈看到别人分享→好奇测试
- 感情/职业迷茫时→寻求指引
- 周末闲暇→自我探索

**核心需求**：

- 获得准确的自我认知
- 找到共鸣和认同
- 获得可执行的建议

#### 👤 用户 B：社交驱动型（21 岁，女性，大学生）

**特征**：

- 社交活跃，喜欢新鲜事物
- 容易被视觉吸引
- 价格敏感但愿为"好玩"付费
- 分享意愿强

**使用场景**：

- 朋友分享测试链接→一起玩
- 情侣/闺蜜合测→对比结果
- 宿舍/班级群讨论→参与话题

**核心需求**：

- 社交货币（有话题可聊）
- 娱乐消遣
- 身份标签（"我是 XX 人格"）

#### 👤 用户 C：实用导向型（28 岁，男性，互联网从业者）

**特征**：

- 理性思维，对"玄学"无感
- 面临职业/人生选择
- 注重科学性和实用性
- 付费意愿高但挑剔

**使用场景**：

- 职业转型期→职业测评
- 团队管理→了解下属性格
- 亲密关系→沟通风格测试

**核心需求**：

- 科学可靠的测试结果
- 可落地的行动建议
- 隐私保护

### 3.2 用户细分场景

| 场景     | 占比 | 核心诉求           | 付费意愿 |
| -------- | ---- | ------------------ | -------- |
| 自我认知 | 35%  | 了解自己是怎样的人 | 中       |

## 6. 详细功能说明

### 6.1 答题系统（P0）

#### 功能描述

用户进行测试的核心界面。

#### 用户流程

```
1. 选择测试 → 点击开始
2. 阅读说明 → 确认开始
3. 逐题作答 → 实时保存进度
4. 完成提交 → 生成报告
```

#### 界面元素

- 题目展示区（题干 + 选项）
- 进度条（已完成/总题数）
- 返回/暂停按钮
- 选项按钮（单选/多选/量表）

#### 交互细节

- 选项点击后有视觉反馈
- 支持左右滑动切换题目
- 支持暂停（进度自动保存）
- 预计完成时间提示

#### 业务规则

- 答题进度实时保存（防止退出丢失）
- 支持中途退出，7 天内可继续
- 每道题必填，不可跳过

└─────────────────────────────────┘
```

**付费解锁层**（完整报告）：

```
1. 人格类型详解
   - 核心特征（5-8 条）
   - 占比数据（"只有 5% 的人是这种人格"）

2. 优势与盲点
   - 优势（3-5 条）
   - 潜在盲点（3-5 条）

3. 适合的职业方向
   - 推荐职业（5-8 个）
   - 工作风格偏好

4. 人际关系建议
   - 沟通风格
   - 适合的伴侣类型
   - 相处建议

5. 个人成长路径
   - 发展建议（3-5 条）
   - 推荐书籍/资源

6. 名人案例
   - 同人格的名人（3-5 个）
```

#### 业务规则

- 免费预览内容足够产生兴趣但不足以获得完整价值
- 付费后永久解锁，可反复查看
- 支持导出 PDF（会员专属）

```

- 深空灰：#333333（主文字）

```
标题：思源黑体 Bold（清晰易读）
正文：思源黑体 Regular
数字：DIN Alternate（数据展示）
```

#### 视觉化呈现

- 人格类型用**颜色 + 图标**标识
- 特征用**雷达图**展示（5 维度）
- 占比用**进度条**展示
- 建议用**卡片**分块展示

#### 阅读体验

- 每屏不超过 3 段文字
- 关键信息加粗/高亮
- 支持"朗读报告"功能（TTS）
- 可收藏/标注重点段落

## 8. 技术架构

### 8.1 技术栈

```
前端：
- 微信小程序原生框架
- 图表：F2（蚂蚁金服图表库）
- 动画：CSS3 + 小程序动画 API

后端：
- Node.js + Express
- 数据库：MongoDB（测试结果）+ Redis（缓存）
- 图片 CDN：阿里云 OSS

服务：
- 支付：微信支付
- 推送：微信模板消息
- 统计：微信小程序分析
- 监控：Sentry + 阿里云 ARMS
```

### 8.3 核心算法

#### 计分逻辑

```javascript
// 示例：MBTI 计分
function calculateMBTI(answers) {
  let scores = {
    E: 0,
    I: 0, // 外向/内向
    S: 0,
    N: 0, // 感觉/直觉
    T: 0,
    F: 0, // 思考/情感
    J: 0,
    P: 0, // 判断/知觉
  };

  answers.forEach((answer) => {
    const scoring = getScoringRule(answer.questionId, answer.selectedOption);
    Object.keys(scoring).forEach((dim) => {
      scores[dim] += scoring[dim];
    });
  });

  // 确定类型
  const type =
    (scores.E >= scores.I ? "E" : "I") +
    (scores.S >= scores.N ? "S" : "N") +
    (scores.T >= scores.F ? "T" : "F") +
    (scores.J >= scores.P ? "J" : "P");

  return { type, scores };
}
```

## 12. 风险与应对

### 12.1 政策风险（低）

**风险**：心理测试可能被判定为"心理咨询"需要资质

**应对**：

- 明确声明"仅供娱乐参考，不构成专业建议"
- 避免"诊断""治疗"等医疗词汇
- 类目选择"工具 - 效率"或"教育 - 知识付费"

### 12.2 内容风险（中）

**风险**：测试结果不准确，用户投诉

**应对**：

- 测试题目经过专业审核
- 结果描述基于心理学研究
- 提供反馈渠道，持续优化

### 12.3 竞争风险（中）

**风险**：市场已有头部产品

**应对**：

- 差异化定位：体验升级 + 年轻化表达
- 内容质量：专业审核 + 可操作建议
- 社交属性：强化分享和互动

### 12.4 商业风险（低）

**风险**：付费转化率低于预期

**应对**：

- MVP 阶段验证付费意愿
- A/B 测试价格点和付费触点
- 多元化收入（单次 + 会员+Premium）

## 附录

### A. 测试题目设计原则

1. **避免引导性**：题目不暗示"正确"答案
2. **情境化**：用具体场景代替抽象描述
3. **选项平衡**：正向/反向选项数量相当
4. **语言简洁**：每道题≤30 字，选项≤15 字

### B. 结果描述原则

1. **具体而非笼统**：避免巴纳姆效应
2. **平衡正负**：优势 + 盲点都描述
3. **可操作**：给出具体建议，不是空话
4. **数据支撑**：引用心理学研究/统计数据
