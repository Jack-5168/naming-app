# 单例模式 (Singleton Pattern)

## 概念

单例模式确保一个类只有一个实例，并提供一个全局访问点来获取该实例。

## 适用场景

- 配置管理器（整个应用只需要一个配置对象）
- 日志记录器（避免多个日志实例写入冲突）
- 数据库连接池（控制连接数量）
- 缓存系统（单一缓存实例）
- 全局状态管理

## 实现方式

### 1. 基础单例（使用闭包）

```javascript
// singleton-basic.js
const Singleton = (function () {
  let instance;

  function createInstance() {
    return {
      name: "Singleton Instance",
      getData() {
        return "Hello from Singleton";
      },
    };
  }

  return {
    getInstance() {
      if (!instance) {
        instance = createInstance();
      }
      return instance;
    },
  };
})();

// 使用示例
const s1 = Singleton.getInstance();
const s2 = Singleton.getInstance();
console.log(s1 === s2); // true - 同一个实例
```

### 2. ES6 Class 单例

```javascript
// singleton-class.js
class Singleton {
  constructor() {
    if (Singleton.instance) {
      return Singleton.instance;
    }

    this.data = [];
    this.name = "Singleton Class Instance";
    Singleton.instance = this;
  }

  addData(item) {
    this.data.push(item);
  }

  getData() {
    return this.data;
  }

  clear() {
    this.data = [];
  }
}

// 使用示例
const s1 = new Singleton();
const s2 = new Singleton();
console.log(s1 === s2); // true

s1.addData("item1");
console.log(s2.getData()); // ['item1'] - 共享数据
```

### 3. 线程安全单例（带锁机制）

```javascript
// singleton-thread-safe.js
class ThreadSafeSingleton {
  constructor() {
    if (ThreadSafeSingleton.instance) {
      return ThreadSafeSingleton.instance;
    }

    this.locked = false;
    this.data = {};
    ThreadSafeSingleton.instance = this;
  }

  async setData(key, value) {
    while (this.locked) {
      await new Promise((resolve) => setTimeout(resolve, 10));
    }
    this.locked = true;
    this.data[key] = value;
    this.locked = false;
  }

  getData(key) {
    return this.data[key];
  }

  getAllData() {
    return { ...this.data };
  }
}

// 使用示例
async function test() {
  const s1 = new ThreadSafeSingleton();
  const s2 = new ThreadSafeSingleton();

  await s1.setData("user", "Alice");
  console.log(s2.getData("user")); // 'Alice'
}

test();
```

### 4. 惰性单例（延迟初始化）

```javascript
// singleton-lazy.js
class LazySingleton {
  constructor() {
    if (LazySingleton.instance) {
      return LazySingleton.instance;
    }

    this.initialized = false;
    this.expensiveResource = null;
    LazySingleton.instance = this;
  }

  // 延迟初始化昂贵资源
  getExpensiveResource() {
    if (!this.initialized) {
      console.log("Initializing expensive resource...");
      this.expensiveResource = {
        created: Date.now(),
        data: "Expensive data loaded",
      };
      this.initialized = true;
    }
    return this.expensiveResource;
  }

  isInitialized() {
    return this.initialized;
  }
}

// 使用示例
const lazy = new LazySingleton();
console.log(lazy.isInitialized()); // false

const resource = lazy.getExpensiveResource(); // 此时才初始化
console.log(lazy.isInitialized()); // true

const lazy2 = new LazySingleton();
console.log(lazy2.getExpensiveResource().created === resource.created); // true
```

## 完整示例：配置管理器

```javascript
// singleton-config-manager.js
class ConfigManager {
  constructor() {
    if (ConfigManager.instance) {
      return ConfigManager.instance;
    }

    this.config = {
      app: {
        name: "MyApp",
        version: "1.0.0",
        debug: false,
      },
      database: {
        host: "localhost",
        port: 5432,
        name: "mydb",
      },
      api: {
        baseUrl: "https://api.example.com",
        timeout: 5000,
      },
    };

    ConfigManager.instance = this;
  }

  get(path) {
    return path.split(".").reduce((obj, key) => obj?.[key], this.config);
  }

  set(path, value) {
    const keys = path.split(".");
    const lastKey = keys.pop();
    const target = keys.reduce((obj, key) => obj[key], this.config);
    if (target && lastKey) {
      target[lastKey] = value;
    }
  }

  getAll() {
    return JSON.parse(JSON.stringify(this.config));
  }

  loadFromFile(configObj) {
    this.config = { ...this.config, ...configObj };
  }
}

// 使用示例
const config1 = new ConfigManager();
const config2 = new ConfigManager();

console.log(config1.get("app.name")); // 'MyApp'
console.log(config1 === config2); // true

config1.set("app.debug", true);
console.log(config2.get("app.debug")); // true - 共享配置
```

## 优缺点

### 优点

- 内存开销小（只有一个实例）
- 避免对资源的多重占用
- 全局访问点，使用方便

### 缺点

- 违反单一职责原则
- 可能导致全局状态污染
- 不利于单元测试（依赖全局状态）
- 在多线程环境下需要额外处理

## 注意事项

1. **测试困难**: 单例的全局状态可能导致测试互相影响
2. **隐藏依赖**: 使用单例的类依赖不明显
3. **并发问题**: 多线程/多进程环境需要特殊处理
4. **过度使用**: 不是所有场景都需要单例
